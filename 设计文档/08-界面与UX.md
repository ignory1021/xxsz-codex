# 08 · 界面与 UX

本文档定义游戏的视觉风格、页面结构、关键交互。

---

## 1. 视觉风格

### 1.1 总体基调

> **古风水墨 + 浅色 + 叙事感**（用户原话）

- **色彩**：浅米黄 / 宣纸白为底，浅青、淡墨、赭石点缀。
- **字体**：标题用书法体（如 楷体 / 行书），正文用宋体或仿宋。
- **装饰**：极简的卷云纹、印章、留白；避免过度装饰。
- **图标**：水墨线稿，少用彩色 icon。

### 1.2 配色（建议）

| 用途 | 颜色 | 备注 |
| --- | --- | --- |
| 背景 | `#F5F1E6`（宣纸白） | 主背景 |
| 次背景 | `#FAF6EC`（米黄） | 卡片背景 |
| 主文字 | `#2A2A2A`（淡墨） |  |
| 弱文字 | `#8A8A8A`（淡墨灰） | 描述、标签 |
| 强调色 | `#3B6E8F`（水墨青） | 链接、按钮 |
| 警示色 | `#A33B3B`（朱砂） | 危险、损耗 |
| 增益色 | `#5A7D4A`（青苔） | 增益、产出 |
| 边框 | `#D9D2C0`（米色边） |  |

### 1.3 字体

| 用途 | 字体 | 备选 |
| --- | --- | --- |
| 标题 | 楷体 / 行楷 | 霞鹜文楷 |
| 正文 | 宋体 | 思源宋体 |
| 数字 | 等线（粗体） | — |

### 1.4 文案风格

**典雅文言 + 半白话**，避免生硬古文：

```
✓ 灵气运转三十六个周天，渐入佳境。
✓ 你步入深谷，但见藤萝垂挂，幽香缕缕。
✗ 你获得了 100 灵气！
✗ 你在山谷中获得了 1 个青灵草！
```

> 数值展示可辅以"+"、"-"等符号，但叙事文案保持文言。

## 2. 移动端优先

### 2.1 屏幕尺寸

- 设计基准：**375 × 667**（iPhone SE）
- 支持：**360 ~ 414 宽度**
- 平板 / 横屏：响应式布局，**不做专门优化**（后期再考虑）

### 2.2 交互手势

- 主要靠**点击**（不是滑动）。
- 关键按钮（修炼 / 冒险 / 炼丹）固定在底部，便于拇指操作。
- 长按查看详情（如材料悬浮卡）。

## 3. 页面结构

### 3.1 总览

```
┌─────────────────────────────────┐
│  顶部状态栏（寿元 / 境界 / 时间） │
├─────────────────────────────────┤
│                                 │
│       主内容区（场景/事件/表单）  │
│                                 │
├─────────────────────────────────┤
│  底部导航栏（修炼/冒险/炼丹/友）  │
├─────────────────────────────────┤
│  时间流控制条（暂停/挂机）       │
└─────────────────────────────────┘
```

- 底部导航栏与时间流控制条固定于视口底部，宽度、左右边界始终与主内容容器对齐。

### 3.2 页面列表

| 页面 | 入口 | 功能 |
| --- | --- | --- |
| **角色卡** | 主菜单 | 展示当前角色所有状态 |
| **修炼** | 底部导航 | 选择难度，设为自动修炼计划 |
| **冒险** | 底部导航 | 选择地图、选择难度，设为自动游历计划 |
| **炼丹** | 底部导航 | 选择丹方、难度，设为自动炼丹计划 |
| **道友** | 底部导航 | 道友列表、详情、互动 |
| **修炼历程** | 顶部菜单 | 行为结算与重要事件的完整时间线 |
| **世系** | 顶部菜单 | 历代记录档 |
| **背包** | 顶部菜单 | 材料 / 丹药 |
| **设置** | 顶部菜单 | 暂停 / 挂机 / 自动行为 / 开新游戏 |
| **角色创建** | 启动 | 姓名 / 性别 / 性格 / 灵根 |

## 4. 关键交互细节

### 4.1 自动行为计划面板

```
┌───────────────────────────────┐
│  [修炼]                       │
│                               │
│  选择难度：                   │
│  ( ) 小周天 · 约 2.4 秒 · +10 │
│  ( ) 入定   · 约 3.2 秒 · +40 │
│  ( ) 闭关   · 约 5.6 秒 · +200│
│                               │
│  ☐ 随机分配                   │
│                               │
│  当前计划：修炼 · 中           │
│  岁序流转时自动开始并续行       │
└───────────────────────────────┘
```

### 4.2 行为进度条

```
┌───────────────────────────────┐
│  修炼中...                    │
│  ████████░░░░░░░░░ 50%        │
│                               │
│  切换计划在本次结束后生效       │
└───────────────────────────────┘
```

### 4.3 行为结算与修炼历程

```
┌───────────────────────────────┐
│  修炼历程                     │
│                               │
│  12年3月 · 吐纳归元           │
│  灵气运转三十六个周天，渐入佳境│
│  灵气 +288                    │
└───────────────────────────────┘
```

- 普通修炼、游历、炼丹的结算不弹窗、不要求确认，自动写入“修炼历程”。
- 玩家通过顶部“历”入口随时查看完整记录；行为页仅展示进行状态与当前计划。
- 只有死亡、转世、飞升等不可逆节点采用强提示。

### 4.4 奇遇与相逢剧情卡

- 修炼或游历触发奇遇、游历触发道友相逢时，展示全屏剧情卡，包含叙事与三项选择；选项不展示数值、成功率或关系结果。
- 剧情卡出现时自动计划暂停；玩家选择后立即写入“修炼历程”，再恢复原计划。
- 道友相逢卡展示姓名、身份与性格；不同选择决定是否结识以及 `-50 ~ 50` 的初始好感度。

### 4.5 重大事件卡（如道友死亡、突破成功）

- 全屏覆盖，停留 3 秒。
- 自动滚动到大事记。
- 关闭按钮 + 继续按钮。

## 5. 大事记

### 5.1 设计意图

> 用户原话："这个游戏也需要一个操作按钮，让用户可以随时自己暂停、放置年龄推进，或者开始游戏。"
> "另外，是不是需要有一个每一段时间的大事记。我不确定是每推进一个年龄就记一次还是怎样，但我觉得这个大事记里面，要让用户有一个可以自由回顾游戏过程的地方。它不一定占据页面比较大的位置，可能详细的用户可以进到具体的页面里面仔细查看。"

大事记 = **关键节点的回顾载体**，不是流水账。

### 5.2 记录的内容

只记录**关键节点**，避免每岁都记：

| 节点 | 是否记录 |
| --- | --- |
| 角色创建 | ✅ |
| 第一次识友 | ✅ |
| 境界层数提升 | 仅每 5 层一次 + 大圆满 |
| 突破成功 | ✅ |
| 突破失败 | ✅ |
| 心境 / 心魔 / 顿悟 | ✅ |
| 炼丹成功（新品阶） | 仅首次 |
| 道友重伤 / 死亡 | ✅ |
| 奇遇 / 机缘 | ✅ |
| 转生 | ✅ |
| 飞升 / 结局 | ✅ |
| 普通的修炼 / 冒险 / 炼丹 | ✅（写入修炼历程，不作为强提示） |

### 5.3 大事记的展示

- 顶部菜单“历”入口。
- 默认折叠到一行：`第一世 · 凡品双灵根 · 凡人结局 · 30 年`，点击展开完整流水。
- 支持按"事件类型"筛选（境界、识友、奇遇）。
- 不占据主屏位置（用户原话）。

### 5.4 离线事件的回填

离线推进的事件**事后回填**到大事记，玩家返回时报告。

## 6. 时间流控制条

### 6.1 位置

固定在屏幕底部，导航栏之上。

### 6.2 UI

```
┌───────────────────────────────┐
│  [⏸ 暂停] [▶ 开始] [⚙ 挂机]   │
│  [x1] [x5] [x10] · 当前1秒/月 │
│  状态：岁序流转中              │
└───────────────────────────────┘
```

### 6.3 状态变化

| 玩家操作 | UI 变化 |
| --- | --- |
| 初次进入 | “已暂停”，等待玩家点击开始 |
| 点击暂停 | "已暂停" + 行为按钮变灰 |
| 点击开始 | “岁序流转中”，年龄按月持续推进 |
| 切换倍率 | x1 / x5 / x10，对应 1 / 0.2 / 0.1 秒每月 |
| 点击挂机 | "挂机中（衰减 30%）" |
| 离线返回 | "离线回归，弹出离线报告" |


### 7.2 飞升画面

- 全屏水墨动画（淡入淡出）。
- 叙事文案用大字楷体滚动。
- 持续 5~10 秒后弹出"结局解锁"提示。

## 8. 性能与可访问性

- **响应时间**：单次行为提交到结果 ≤ 100ms。
- **本地存档**：所有数据存 localStorage（不联网）。
- **离线可用**：PWA 友好，未来支持。
- **字号**：基础 16px，可调整到 18px / 20px。
- **色弱友好**：不依赖单一颜色表达信息。

---

## 9. 后续扩展（1.x / 2.x）

- **暗色模式**：夜晚模式（不破坏古风）。
- **自定义主题**：玩家可选不同书法体 / 配色。
- **音效**：古风琴箫配乐，可关闭。
- **触觉反馈**：震动（移动端）。
