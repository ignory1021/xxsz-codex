# 08 · 界面与 UX

本文档定义游戏的视觉风格、页面结构、关键交互。

---

## 1. 视觉风格

### 1.1 总体基调

> **古风水墨 + 浅色 + 叙事感**（用户原话）

- **色彩**：浅米黄 / 宣纸白为底，浅青、淡墨、赭石点缀。
- **字体**：标题用书法体（如 楷体 / 行书），正文用宋体或仿宋。
- **装饰**：极简的卷云纹、印章、留白；避免过度装饰。
- **图标**：水墨线稿，少用彩色 icon。

### 1.2 配色（建议）

| 用途 | 颜色 | 备注 |
| --- | --- | --- |
| 背景 | `#F5F1E6`（宣纸白） | 主背景 |
| 次背景 | `#FAF6EC`（米黄） | 卡片背景 |
| 主文字 | `#2A2A2A`（淡墨） |  |
| 弱文字 | `#8A8A8A`（淡墨灰） | 描述、标签 |
| 强调色 | `#3B6E8F`（水墨青） | 链接、按钮 |
| 警示色 | `#A33B3B`（朱砂） | 危险、损耗 |
| 增益色 | `#5A7D4A`（青苔） | 增益、产出 |
| 边框 | `#D9D2C0`（米色边） |  |

### 1.3 字体

| 用途 | 字体 | 备选 |
| --- | --- | --- |
| 标题 | 楷体 / 行楷 | 霞鹜文楷 |
| 正文 | 宋体 | 思源宋体 |
| 数字 | 等线（粗体） | — |

### 1.4 文案风格

**典雅文言 + 半白话**，避免生硬古文：

```
✓ 炉火映照丹室，药香自缝隙间缓缓逸出。
✓ 你步入深谷，但见藤萝垂挂，幽香缕缕。
✗ 你获得了 100 点丹道经验！
✗ 你在山谷中获得了 1 个青灵草！
```

> 数值展示可辅以"+"、"-"等符号，但叙事文案保持文言。

## 2. 移动端优先

### 2.1 屏幕尺寸

- 设计基准：**375 × 667**（iPhone SE）
- 支持：**360 ~ 414 宽度**
- 平板 / 横屏：响应式布局，**不做专门优化**（后期再考虑）

### 2.2 交互手势

- 主要靠**点击**（不是滑动）。
- 关键按钮（探索 / 炼丹 / 集市）固定在底部，便于拇指操作。
- 长按查看详情（如材料悬浮卡）。

## 3. 页面结构

### 3.1 总览

```
┌─────────────────────────────────┐
│  顶部状态栏（寿元 / 境界 / 时间） │
├─────────────────────────────────┤
│                                 │
│       主内容区（场景/事件/表单）  │
│                                 │
├─────────────────────────────────┤
│  底部导航栏（探索/炼丹/集市/友）  │
└─────────────────────────────────┘
```

- 底部导航栏固定于视口底部，宽度、左右边界始终与主内容容器对齐。

### 3.2 页面列表

| 页面 | 入口 | 功能 |
| --- | --- | --- |
| **角色卡** | 主菜单 | 展示当前角色所有状态 |
| **探索** | 底部导航 | 选择地图并完成一次探索行动 |
| **炼丹** | 底部导航 | 选择丹方并完成一次炼丹行动 |
| **集市** | 底部导航 | 出售丹药、购买装备与恢复品 |
| **道友** | 底部导航 | 道友列表、详情、互动 |
| **修炼历程** | 顶部菜单 | 行为结算与重要事件的完整时间线 |
| **世系** | 顶部菜单 | 历代记录档 |
| **背包** | 顶部菜单 | 材料 / 丹药 |
| **设置** | 顶部菜单 | 音效、文字速度、开新游戏 |
| **角色创建** | 启动 | 姓名 / 性别 / 性格 / 灵根 |

## 4. 关键交互细节

### 4.1 行动确认面板

```
┌───────────────────────────────┐
│  [探索]                       │
│                               │
│  选择地图：                   │
│  ( ) 青岚山谷 · 路费 / 体力   │
│  ( ) 迷雾古洞 · 推荐攻防      │
│                               │
│  ☐ 随机分配                   │
│                               │
│  本次消耗：体力、路费、10天寿元 │
│  [踏入山中]                     │
└───────────────────────────────┘
```

### 4.2 行为进度条

```
┌───────────────────────────────┐
│  青岚山谷                      │
│  ████████░░░░░░░░░ 50%        │
│                               │
│  本次结算后年龄推进 10 天       │
└───────────────────────────────┘
```

### 4.3 行为结算与修炼历程

```
┌───────────────────────────────┐
│  修行历程                     │
│                               │
│  12年3月 · 青岚山谷           │
│  山径尽头发现一丛青灵草        │
│  灵草 +1 · 体力 -1            │
└───────────────────────────────┘
```

- 普通探索、炼丹、调息的结算不弹窗、不要求确认，自动写入“修行历程”。
- 玩家通过顶部“历”入口随时查看完整记录；行为页展示本次资源与寿元消耗。
- 只有死亡、转世、飞升等不可逆节点采用强提示。

### 4.4 奇遇与相逢剧情卡

- 探索触发奇遇或道友相逢时，展示全屏剧情卡，包含叙事与三项选择；选项不展示数值、成功率或关系结果。
- 玩家选择后立即写入“修行历程”，再回到行动页面。
- 道友相逢卡展示姓名、身份与性格；不同选择决定是否结识以及 `-50 ~ 50` 的初始好感度。

### 4.5 重大事件卡（如道友死亡、突破成功）

- 全屏覆盖，停留 3 秒。
- 自动滚动到大事记。
- 关闭按钮 + 继续按钮。

## 5. 大事记

### 5.1 设计意图

> 大事记需要让用户可以自由回顾每次行动、战斗、炼丹与重要选择，但不占据主页面主要空间。

大事记 = **关键节点的回顾载体**，不是流水账。

### 5.2 记录的内容

只记录**关键节点**，避免每岁都记：

| 节点 | 是否记录 |
| --- | --- |
| 角色创建 | ✅ |
| 第一次识友 | ✅ |
| 境界层数提升 | 仅每 5 层一次 + 大圆满 |
| 突破成功 | ✅ |
| 突破失败 | ✅ |
| 心境 / 心魔 / 顿悟 | ✅ |
| 炼丹成功（新品阶） | 仅首次 |
| 道友重伤 / 死亡 | ✅ |
| 奇遇 / 机缘 | ✅ |
| 转生 | ✅ |
| 飞升 / 结局 | ✅ |
| 普通的探索 / 炼丹 / 调息 | ✅（写入修行历程，不作为强提示） |

### 5.3 大事记的展示

- 顶部菜单“历”入口。
- 默认折叠到一行：`第一世 · 凡品双灵根 · 凡人结局 · 30 年`，点击展开完整流水。
- 支持按"事件类型"筛选（境界、识友、奇遇）。
- 不占据主屏位置（用户原话）。

## 6. 转生 / 飞升的画面

### 6.1 转生确认

```
┌───────────────────────────────┐
│  寿元已尽...                  │
│                               │
│  李青云合上了眼。             │
│  这一世，你走过了 30 年。     │
│                               │
│  [转生]  [开新游戏]           │
└───────────────────────────────┘
```

### 6.2 飞升画面

- 全屏水墨动画（淡入淡出）。
- 叙事文案用大字楷体滚动。
- 持续 5~10 秒后弹出"结局解锁"提示。

---

## 7. 性能与可访问性

- **响应时间**：单次行为提交到结果 ≤ 100ms。
- **本地存档**：所有数据存 localStorage（不联网）。
- **离线可用**：PWA 友好，未来支持。
- **字号**：基础 16px，可调整到 18px / 20px。
- **色弱友好**：不依赖单一颜色表达信息。

---

## 9. 后续扩展（1.x / 2.x）

- **暗色模式**：夜晚模式（不破坏古风）。
- **自定义主题**：玩家可选不同书法体 / 配色。
- **音效**：古风琴箫配乐，可关闭。
- **触觉反馈**：震动（移动端）。
