# 修仙手札 · 设计文档

一款手机优先的主动行动式炼丹修仙文字游戏。本目录是该项目的设计文档集合。

---

## 一、项目定位

- **形态**：模块化文字行动 / 资源经营游戏
- **平台**：第一期 = 手机浏览器（响应式网页）；后期 = 安卓 APK 移植
- **风格**：古风水墨 + 典雅文言
- **节奏**：短反馈、快节奏，玩家可在任意 1~5 分钟空隙内推进游戏，不打断现实生活

参考作品：《某某宗女修修炼手札》《药王谷女修修炼手札》。本项目保留修仙叙事与多世因缘，但以主动行动、寿元抉择和炼丹经营为核心。

## 三、关键设计决策（摘要）

> 这些是经过需求讨论后定下的核心原则，详细机制见对应文档。

### 1. 核心循环

```
探索 ─► 材料 ─► 炼丹 ─► 丹道经验 / 丹药 ─► 灵石 / 装备 / 补给
  │                                                        │
  └────────────────── 境界提升 / 高阶地图解锁 ◄─────────────┘
                                │
                                ▼
                       寿元耗尽 = 死亡
                                │
                                ▼
                       转生（因缘延续） / 飞升（多结局）
```

- **寿元**：年龄仅在探索、炼丹、调息等行动结算时按天推进；到达上限即死亡。
- **探索**：消耗体力与路费，取得材料、战利品与文字遭遇。
- **炼丹**：消耗材料、精力与炉费，获得丹道经验与丹药，是主要成长来源。
- **集市与装备**：出售丹药获得灵石，购买装备、补给与恢复品，进入高阶地图。
- **非放置**：离线不推进年龄、不恢复资源；所有成长与消耗都由玩家主动行动触发。

### 2. 节奏

- **初期快** → **中期中等** → **后期慢**：练气期 30 分钟~2 小时走完一个大境界，之后逐境界变慢。
- **单次行为**：探索、炼丹、调息均为一次性主动结算，明确展示资源与寿元天数消耗。

### 3. 灵根

- 五行固定：金、木、水、火、土；可随机出天灵根 / 变异灵根。
- **灵根**：决定五行丹方、装备与事件倾向；资质可被丹药调整，但转生后重新生成。

### 4. 境界

完整体系（练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升），每个大境界分 10 层 + 大圆满 + 突破。

### 5. 转生

- **重置循环 + 因缘延续**：寿元耗尽 = 转生；除世系记录与部分道友的转世重逢外，全部数值、经济资产与物品重置。
- **开新游戏**：玩家主动选择"开新游戏"时，丢弃所有前世记录，包括记录档。

### 6. 多结局

记录档记录每一世（第一世……第 N 世）的关键信息，开新游戏则清空。在游戏中转生则保留记录档。

## 四、MVP 范围（本期）

**做**：
- 角色创建（姓名 / 性别 / 性格 / 随机灵根）
- 单次探索（路费、体力与寿元消耗，纯文字事件 + 轻量攻防判定）
- 炼丹系统（材料、炉费与精力消耗，丹道经验与丹药产出）
- 集市与装备（出售丹药、购买装备、补给与恢复品）
- 道友系统（识别、好感度、组队、绝交、可抢救死亡）
- 境界 1~10 层 + 大圆满 + 突破（失败随机跌落 + 重伤）
- 转生（重置个人资质 + 部分道友转世重逢）
- 多结局 + 世系记录档
- 主动行动、寿元消耗与行动历程
- 大事记（重要节点回顾）

**不做**（留作后续扩展）：
- 宗门系统
- 战斗系统（仅保留纯文字战斗描述）
- 完整功法 / 技能系统（MVP 仅做"每境界解锁一个默认功法"作为叙事）
- 地图系统（MVP 仅按境界解锁地图名 + 文字描述）
- 道侣系统
- 主线剧情 / 多分支选项（仅轻量叙事 + 随机事件）
- 云存档（MVP 仅 localStorage）

详细分期见 [08-分期路线图](./08-分期路线图.md)。
