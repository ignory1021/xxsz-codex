# 修仙手札 · 设计文档

一款手机优先的实时挂机修仙文字游戏。本目录是该项目的设计文档集合。

---

## 一、项目定位

- **形态**：模块化文字放置 / 挂机游戏
- **平台**：第一期 = 手机浏览器（响应式网页）；后期 = 安卓 APK 移植
- **风格**：古风水墨 + 典雅文言
- **节奏**：短反馈、快节奏，玩家可在任意 1~5 分钟空隙内推进游戏，不打断现实生活

参考作品：《某某宗女修修炼手札》《药王谷女修修炼手札》。本项目在保留其核心循环的同时，朝"挂机可中断、可暂停、可异步推进"的方向收敛。

## 三、关键设计决策（摘要）

> 这些是经过需求讨论后定下的核心原则，详细机制见对应文档。

### 1. 核心循环

```
年龄持续推进 ─► 修炼 / 冒险 / 炼丹 ─► 灵气 / 材料 / 丹药 / 事件
        │                                                │
        │                                                ▼
        └──────────── 境界提升 / 寿元上限提升 ◄────────────┘
                                │
                                ▼
                       寿元耗尽 = 死亡
                                │
                                ▼
                       转生（因缘延续） / 飞升（多结局）
```

- **寿元**：年龄在玩家点击“开始”后持续推进，行为还会额外推进对应年月；到达上限即死亡。可通过升境界、丹药、机缘提升上限。
- **修炼**：主线，稳定的灵气来源。
- **冒险**：辅助，产出材料、触发随机事件（识友、奇遇、战斗文本）。
- **炼丹**：辅助，材料转化为丹药，丹药反哺灵气、寿元上限、灵根净化、突破成功率。
- **离线**：部分挂机 + 效率衰减，上限随境界提升（练气 30 年、筑基 50 年、金丹 100 年……）。

### 2. 节奏

- **初期快** → **中期中等** → **后期慢**：练气期 30 分钟~2 小时走完一个大境界，之后逐境界变慢。
- **单次行为**：修炼、冒险、炼丹均为几秒钟短时挂机，有进度条，期间不能并发其他行为。

### 3. 灵根

- 五行固定：金、木、水、火、土；可随机出天灵根 / 变异灵根。
- **灵根结构系数 × 资质 = 收益**：两者并重，乘法关系。资质可被“净灵丹”等丹药提升，但转生后重新生成。

### 4. 境界

完整体系（练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升），每个大境界分 10 层 + 大圆满 + 突破。

### 5. 转生

- **常规循环 + 因缘积累**：寿元耗尽 = 转生；灵根、悟性、悟道点重置，部分道友会以新身份转世重逢。
- **开新游戏**：玩家主动选择"开新游戏"时，丢弃所有前世记录，包括记录档。

### 6. 多结局

记录档记录每一世（第一世……第 N 世）的关键信息，开新游戏则清空。在游戏中转生则保留记录档。

## 四、MVP 范围（本期）

**做**：
- 角色创建（姓名 / 性别 / 性格 / 随机灵根）
- 短时挂机修炼
- 大地图冒险（纯文字事件 + 轻量遭遇判定，无完整战斗系统）
- 炼丹系统（中等复杂度：20~30 种丹方 + 30+ 材料带词条）
- 道友系统（识别、好感度、组队、绝交、可抢救死亡）
- 境界 1~10 层 + 大圆满 + 突破（失败随机跌落 + 重伤）
- 转生（重置个人资质 + 部分道友转世重逢）
- 多结局 + 世系记录档
- 离线挂机 + 暂停 / 推进按钮
- 大事记（重要节点回顾）

**不做**（留作后续扩展）：
- 宗门系统
- 战斗系统（仅保留纯文字战斗描述）
- 完整功法 / 技能系统（MVP 仅做"每境界解锁一个默认功法"作为叙事）
- 地图系统（MVP 仅按境界解锁地图名 + 文字描述）
- 道侣系统
- 主线剧情 / 多分支选项（仅轻量叙事 + 随机事件）
- 云存档（MVP 仅 localStorage）

详细分期见 [09-分期路线图](./09-分期路线图.md)。
