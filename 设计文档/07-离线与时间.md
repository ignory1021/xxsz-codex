# 07 · 离线与时间

本文档定义离线挂机机制、推进上限、时间流控制。

---

## 1. 设计目标

- 玩家可以随时打开游戏，推进几分钟，也可以长时间离开后回来。
- **离线 ≠ 浪费**：离线时仍有一定推进，但有上限，避免长期离线比在线更划算。
- 玩家可以**主动控制时间流**（暂停 / 推进 / 开始），不强制时刻在线。

---

## 2. 时间流的三种状态

| 状态 | 寿元是否推进 | 触发方式 |
| --- | --- | --- |
| **暂停** | 否 | 玩家主动开启 |
| **推进** | 是（持续基础推进 + 行为额外推进） | 玩家点击“开始” |
| **离线挂机** | 是（衰减） | 浏览器后台 / 关闭标签 |

---

## 3. 离线挂机机制

### 3.1 核心规则

- 离线时，以 x1 的“现实 3 秒 = 游戏 1 个月”为基准，按 **效率衰减** 推进。
- 离线推进受**上限**约束（详见 §4）。
- 玩家主动暂停后退出，离线期间也保持冻结，不计算任何推进。

### 3.2 衰减系数

| 离线时长 | 效率 |
| --- | --- |
| 0 ~ 1 小时 | 100% |
| 1 ~ 6 小时 | 80% |
| 6 ~ 24 小时 | 50% |
| 24 小时以上 | 30% |

> 例：玩家离线 10 小时，效率加权平均 = (1×100% + 5×80% + 4×50%) ÷ 10 ≈ 70%。
> 离线基础月数 = floor(已有月进度余量 + 现实离线秒数 ÷ 3 × 分段效率)。离线与挂机固定使用 x1 基准，不继承离线前的 x3 / x5 在线倍率；不足 1 个月的结果继续保存为月进度余量。

### 3.3 离线推进的范围

离线推进会模拟玩家的"自动行为"：

| 行为 | 离线时是否执行 | 执行规则 |
| --- | --- | --- |
| **修炼** | ✅ | 按自动行为偏好 |
| **冒险** | ✅ | 按自动行为偏好 |
| **炼丹** | ✅ | 按自动行为偏好（仅当有材料时） |
| **道友事件** | ✅ | 由模拟行为正常触发 |
| **心境事件** | ✅ | 同在线 |
| **突破尝试** | ❌ | 仅玩家手动 |

> 离线时**不会自动突破**，避免玩家错过时机。
> 系统先计算可推进的寿元预算，再按在线行为成本模拟自动行为；事件概率与在线一致，不再按“每年”额外重复抽取。

### 3.4 离线报告

玩家返回游戏时，弹出离线报告卡：

```
[离线报告]
  离线时长：10 小时
  推进寿元：30 年（已达练气离线上限）
  修炼次数：12 次
  冒险次数：2 次
  炼丹次数：1 次
  识友事件：0 次
  所得灵气：480
  获得材料：青灵草 ×3、朱砂 ×1
  突破事件：无
  重大事件：无
```

- 报告用**典雅文言**风格概述。
- 玩家点击"确认"后正式进入游戏。

## 4. 离线推进上限

### 4.1 上限公式

上限与**当前境界**挂钩（用户原话："练气 30 年、筑基 50 年、金丹 100 年"）：

| 境界 | 离线推进上限 |
| --- | --- |
| 练气 | 30 年 |
| 筑基 | 50 年 |
| 金丹 | 100 年 |
| 元婴 | 300 年 |
| 化神 | 500 年 |
| 炼虚 | 1,000 年 |
| 合体 | 2,000 年 |
| 大乘 | 3,000 年 |
| 渡劫 | 5,000 年 |

> 设计意图：高境界的离线推进上限大幅提升，让"挂机流"玩家也能推进。

### 4.2 上限的应用

```
实际推进 = min(离线时间对应寿元, 离线上限)
```

- 若实际离线时间 > 离线上限对应的现实时间，多余时间**不补**（保护平衡）。
- 上限在配置中统一换算为月数计算，界面仍按“年 / 月”展示。

### 4.3 上限的边界情况

- 玩家当前寿元已接近上限时，离线推进到上限即停止（不会溢出）。
- 离线推进触发转生时，正常弹出转生确认（详见 [06-转生与多结局](./06-转生与多结局.md)）。

## 5. 时间流控制按钮

玩家在主界面可以控制时间流状态：

### 5.1 按钮列表

| 按钮 | 行为 | UI 状态 |
| --- | --- | --- |
| **暂停** | 冻结寿元推进，关闭自动行为 | 显示"⏸ 已暂停" |
| **开始** | 恢复基础时间流，年龄按当前倍率持续推进 | 显示"▶ 进行中" |
| **挂机** | 强制进入离线模式（即便浏览器在前台） | 显示"⚙ 挂机中" |

### 5.2 暂停的边界

- **暂停时**：行为提交按钮变灰，无法点击。
- **暂停时**：依然可以查看道友、大事记、记录档（只读）。
- **暂停时**：离线衰减不计算（玩家主动暂停 = 完全冻结）。

### 5.3 挂机模式

- 玩家主动开启"挂机"后，游戏即使在前台也按离线效率推进。
- 适合"睡前挂着"或"挂着炼丹"的场景。
- 挂机模式有单独的进度展示（如"已挂机 X 小时"）。

## 6. 时间流的细节

### 6.1 现实时间 vs 游戏内时间

游戏按月推进，内部只保存整数月。x1 下现实 3 秒推进游戏 1 个月，因此现实 36 秒推进游戏 1 年。

| 倍率 | 每推进 1 个月所需现实时间 | 适用范围 |
| --- | --- | --- |
| x1 | 3 秒 | 在线基础、离线与挂机基准 |
| x3 | 1 秒 | 仅在线开始状态 |
| x5 | 0.6 秒 | 仅在线开始状态 |

实现时不依赖定时器触发次数，而是根据前后时间戳计算完整月数，避免浏览器切换后台造成漏算或重复推进。年龄保存为整数月，未满一个月的进度保存为 `0~1` 的月进度余量，暂停期间不增加余量。

```
游戏内行为额外推进
   │
   ├── 轻难度行为：消耗 1 月 / 次
   ├── 中难度行为：消耗 3 月 / 次
   ├── 重难度行为：消耗 1 年 / 次
   └── 超难度行为：消耗 5 年 / 次
```

> 一世总寿命 1 万年 = 数万次行为（不算离线）。

基础年龄持续推进与行为额外推进同时存在：

```
本次年龄变化（月） = 行为期间完成的基础月份 + 行为难度对应的额外月份
```

### 6.2 行为进度时间

| 行为 | 进度时间（秒） |
| --- | --- |
| 修炼（任意难度） | 2 ~ 4 秒 |
| 冒险（轻 / 中 / 重 / 超） | 3 / 5 / 8 / 12 秒 |
| 炼丹（同上） | 3 / 5 / 8 / 12 秒 |

> 进度时间不改变行为本身的额外寿元成本，仅影响“手感”；但行为期间基础年龄仍按当前倍率逐月推进。x1 / x3 / x5 不加速行为进度条。

### 6.3 自动行为的可配置性

玩家可以设置"自动行为偏好"：

| 设置 | 选项 |
| --- | --- |
| 自动行为时优先 | 修炼 / 冒险 / 炼丹 / 平衡 |
| 自动行为难度 | 轻 / 中 / 重 / 超 / 推荐 |
| 自动识友 | 接受 / 拒绝 / 自动 |

> 玩家在挂机时的体验可以通过这些设置调优。

---

## 7. 与存档的交互

- **暂停**：存档中标记 `paused: true`。
- **挂机**：存档中标记 `idleMode: true`。
- **离线推进的计算**在每次玩家打开游戏时计算，不在后台计算（节省电、保护隐私）。
