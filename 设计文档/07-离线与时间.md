# 07 · 离线与时间

本文档定义离线挂机机制、推进上限、时间流控制。

---

## 1. 设计目标

- 玩家可以随时打开游戏，推进几分钟，也可以长时间离开后回来。
- **离线 ≠ 浪费**：离线时仍有一定推进，但有上限，避免长期离线比在线更划算。
- 玩家可以**主动控制时间流**（暂停 / 推进 / 开始），不强制时刻在线。

---

## 2. 时间流的三种状态

| 状态 | 寿元是否推进 | 触发方式 |
| --- | --- | --- |
| **暂停** | 否 | 玩家主动开启 |
| **推进** | 是（玩家每次行为） | 默认状态 |
| **离线挂机** | 是（衰减） | 浏览器后台 / 关闭标签 |

---

## 3. 离线挂机机制

### 3.1 核心规则

- 离线时，寿元按 **效率衰减** 推进。
- 离线推进受**上限**约束（详见 §4）。

### 3.2 衰减系数

| 离线时长 | 效率 |
| --- | --- |
| 0 ~ 1 小时 | 100% |
| 1 ~ 6 小时 | 80% |
| 6 ~ 24 小时 | 50% |
| 24 小时以上 | 30% |

> 例：玩家离线 10 小时，效率加权平均 ≈ 60%。
> 实际推进寿元 = 在线时长 × 在线效率（按 §4.2 表计算）。

### 3.3 离线推进的范围

离线推进会模拟玩家的"自动行为"：

| 行为 | 离线时是否执行 | 触发概率 |
| --- | --- | --- |
| **修炼** | ✅ | 默认 |
| **冒险** | ✅ | 20% / 年寿元 |
| **炼丹** | ✅ | 10% / 年寿元（仅当有材料时） |
| **道友事件** | ✅ | 30% / 年寿元 |
| **心境事件** | ✅ | 同在线 |
| **突破尝试** | ❌ | 仅玩家手动 |

> 离线时**不会自动突破**，避免玩家错过时机。

### 3.4 离线报告

玩家返回游戏时，弹出离线报告卡：

```
[离线报告]
  离线时长：10 小时
  推进寿元：3 年
  修炼次数：12 次
  冒险次数：2 次
  炼丹次数：1 次
  识友事件：0 次
  所得灵气：480
  获得材料：青灵草 ×3、朱砂 ×1
  突破事件：无
  重大事件：无
```

- 报告用**典雅文言**风格概述。
- 玩家点击"确认"后正式进入游戏。

## 4. 离线推进上限

### 4.1 上限公式

上限与**当前境界**挂钩（用户原话："练气 30 年、筑基 50 年、金丹 100 年"）：

| 境界 | 离线推进上限 |
| --- | --- |
| 练气 | 30 年 |
| 筑基 | 50 年 |
| 金丹 | 100 年 |
| 元婴 | 300 年 |
| 化神 | 500 年 |
| 炼虚 | 1,000 年 |
| 合体 | 2,000 年 |
| 大乘 | 3,000 年 |
| 渡劫 | 5,000 年 |

> 设计意图：高境界的离线推进上限大幅提升，让"挂机流"玩家也能推进。

### 4.2 上限的应用

```
实际推进 = min(离线时间对应寿元, 离线上限)
```

- 若实际离线时间 > 离线上限对应的现实时间，多余时间**不补**（保护平衡）。
- 上限按"年"计算，而不是"现实小时"，避免误解。

### 4.3 上限的边界情况

- 玩家当前寿元已接近上限时，离线推进到上限即停止（不会溢出）。
- 离线推进触发转生时，正常弹出转生确认（详见 [06-转生与多结局](./06-转生与多结局.md)）。

## 5. 时间流控制按钮

玩家在主界面可以控制时间流状态：

### 5.1 按钮列表

| 按钮 | 行为 | UI 状态 |
| --- | --- | --- |
| **暂停** | 冻结寿元推进，关闭自动行为 | 显示"⏸ 已暂停" |
| **开始** | 恢复时间流，进入"推进"状态 | 显示"▶ 进行中" |
| **挂机** | 强制进入离线模式（即便浏览器在前台） | 显示"⚙ 挂机中" |

### 5.2 暂停的边界

- **暂停时**：行为提交按钮变灰，无法点击。
- **暂停时**：依然可以查看道友、大事记、记录档（只读）。
- **暂停时**：离线衰减不计算（玩家主动暂停 = 完全冻结）。

### 5.3 挂机模式

- 玩家主动开启"挂机"后，游戏即使在前台也按离线效率推进。
- 适合"睡前挂着"或"挂着炼丹"的场景。
- 挂机模式有单独的进度展示（如"已挂机 X 小时"）。

## 6. 时间流的细节

### 6.1 现实时间 vs 游戏内时间

游戏内 1 年 ≠ 现实 1 年。

```
游戏内 1 年（基础）
   │
   ├── 轻难度行为：消耗 1 月 / 次
   ├── 中难度行为：消耗 3 月 / 次
   ├── 重难度行为：消耗 1 年 / 次
   └── 超难度行为：消耗 5 年 / 次
```

> 一世总寿命 1 万年 = 数万次行为（不算离线）。

### 6.2 行为进度时间

| 行为 | 进度时间（秒） |
| --- | --- |
| 修炼（任意难度） | 2 ~ 4 秒 |
| 冒险（轻 / 中 / 重 / 超） | 3 / 5 / 8 / 12 秒 |
| 炼丹（同上） | 3 / 5 / 8 / 12 秒 |

> 进度时间不影响寿元消耗，仅影响"手感"。

### 6.3 自动行为的可配置性

玩家可以设置"自动行为偏好"：

| 设置 | 选项 |
| --- | --- |
| 自动行为时优先 | 修炼 / 冒险 / 炼丹 / 平衡 |
| 自动行为难度 | 轻 / 中 / 重 / 超 / 推荐 |
| 自动识友 | 接受 / 拒绝 / 自动 |

> 玩家在挂机时的体验可以通过这些设置调优。

---

## 7. 与存档的交互

- **暂停**：存档中标记 `paused: true`。
- **挂机**：存档中标记 `idleMode: true`。
- **离线推进的计算**在每次玩家打开游戏时计算，不在后台计算（节省电、保护隐私）。
