# 01 · 核心循环

本文档定义“炼丹修仙”版本的主动行动循环与寿元规则。

---

## 1. 一句话闭环

> **探索消耗寿元、体力与路费 → 取得材料 → 炼丹消耗寿元、精力与炉费 → 获得丹道经验与丹药 → 卖丹取得灵石 → 购买装备与补给 → 探索更高阶地图 → 境界提升并延长寿元。**

寿元是行动次数的上限。玩家在有限寿元中选择探索、炼丹、出售、购买、调息与战斗风险。

## 2. 行动式时间

| 项目 | 规则 |
| --- | --- |
| 年龄单位 | 整数天；1 年 = 360 天，1 月 = 30 天，界面展示年 / 月 / 天 |
| 年龄推进 | 仅由玩家主动行动结算时推进 |
| 行动结算 | 先结算所得与层级提升，再推进寿元；达到上限后进入当世结局 |

- 基础探索与基础炼丹各消耗 **30 ± 10 天**。
- 中阶探索与中阶炼丹各消耗 **60 ± 20 天**。
- 高阶探索与高阶炼丹各消耗 **90 ± 30 天**。

每次行动在对应区间内随机抽取整数天数，并在结算后展示实际消耗。寿元不足以覆盖本次行动时仍可开始；行动所得、丹道经验及由此触发的寿元上限提升均先结算，再判定是否寿尽。


## 3. 玩家行动

每次操作只完成一个行动：

```
[选择探索 / 炼丹 / 调息 / 集市] → [检查资源与寿元] → [结算结果 + 推进天数] → [玩家选择下一步]
```

- **探索**：支付路费，消耗体力与寿元，取得材料并可能遇妖、识友或触发奇遇。
- **炼丹**：消耗材料、精力、炉费与寿元，成功获得丹道经验和丹药。
- **集市**：出售丹药、购买装备和恢复品，不推进寿元。
- **调息**：消耗寿元恢复体力与精力，不提供主要丹道经验。

资源不足时不允许行动，并明确列出缺少项；系统不会自动购买补给或自动出售丹药。

## 4. 成长与风险

| 环节 | 成长 / 风险 |
| --- | --- |
| 炼丹 | 丹道经验提升层级与境界，是主要成长来源 |
| 境界 | 解锁高阶地图、丹方与装备，并提高寿元上限 |
| 灵根 | 五行根值分别支撑炼丹、攻击、防御、采集与生命，并随层级成长 |
| 装备 | 提高攻击与防御等派生属性，降低高阶地图的文字战斗风险 |
| 战斗 | 玩家选择迎战或退避；胜利有固定额外产出，失败生命降至 1、保留全部保底材料并可能获得轻伤 |
| 经济 | 灵石支付路费、炉费、装备与恢复品，避免资源只增不减 |

## 5. 转世

寿元耗尽后，当世结算结束。境界、丹道经验、灵石、装备、材料、丹药、丹方、体力、精力与消耗品全部清零；仅世系记录及符合因缘条件的道友魂识保留，用于下一世重逢叙事。
