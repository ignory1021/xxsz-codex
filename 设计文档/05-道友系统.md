# 05 · 道友系统

道友是游戏中除主角外的核心 NPC，承担 **社交、协助、叙事** 三重职能。

---

## 1. 设计目标

- 让玩家感觉"修仙路上不孤单"，但不强制社交。
- 道友是有 **独立意志** 的角色，会成长、会受伤、会死亡。
- 好感度系统需要让玩家**有得失感**，但不让社交成为负担。

---

## 2. 识别 / 认识

### 2.1 触发方式：**纯随机事件**

道友在以下场景中可能被识别：

| 场景 | 概率 | 备注 |
| --- | --- | --- |
| 冒险中 | 10% / 每次冒险结算 | 主要识别场景 |
| 修炼中 | 0.5% / 每次修炼结算 | 心境澄明 → 偶遇 |
| 炼丹中 | 0.1% / 每次炼丹结算 | 极罕见 |
| 奇遇事件 | 100%（触发即识友） | 剧情向 |
| 主动寻访（后期） | 主动 | 解锁后 |

### 2.2 道友的生成

道友由**姓库与名库**随机组合生成（MVP 各内置 20 个以上条目），每个 NPC 有：

| 字段 | 说明 |
| --- | --- |
| **姓名** | 古风姓名，与主角性别无绑定 |
| **性别** | 独立字段，影响文案 |
| **性格** | 豪迈 / 谨慎 / 阴鸷 / 豁达 / 温和 / 孤僻 |
| **灵根** | 1~5 个，独立资质 |
| **境界** | 等于或略低于主角当前境界 |
| **寿元上限** | 与境界匹配 |
| **当前寿元** | 初始为 0.3 × 上限 |
| **好感度** | 初始 0（陌生人）~ 30（点头之交） |
| **背景故事** | 1~3 句叙事描述 |
| **专属事件** | 1~3 个事件 ID（好感度高时触发） |

- 同一世中新结识的道友会排除本世已经结识过的姓名，不会出现重名。
- 姓名仅用于展示；每位道友仍以独立魂识 ID 记录，支撑后续的转世重逢。

### 2.3 识别的交互

```
[识别事件触发]  ──►  [展示道友基础信息 + 简短背景]
                                  │
                                  ▼
                [选项：执礼相邀 / 平常相问 / 锋芒相试]
                                  │
                  ┌───────────────┴───────────────┐
                  ▼                               ▼
             [结识并加入因缘簿]                 [暂不结识]
                  │                               │
                  ▼                               ▼
         初始好感度按选择确定                 此 NPC 不再出现
```

- **执礼相邀**：道友加入道友列表，初始好感度随机为 **20 ~ 50**。
- **平常相问**：道友加入道友列表，初始好感度随机为 **-10 ~ 20**。
- **锋芒相试**：道友加入道友列表，初始好感度随机为 **-50 ~ -15**，以亦敌亦友的关系开始。
- 每种选择的结果都会弹窗呈现，并写入修炼历程；选定后自动恢复此前的行为计划。

## 3. 好感度

### 3.1 数值范围

```
-100  0   30   50   70   90   100
  │   │   │    │    │    │    │
  仇  陌  点头 知交 莫逆 至交 道侣(后期)
```

### 3.2 好感度的变化

| 行为 | 变化 |
| --- | --- |
| **随机事件 +** | 1 ~ 5 |
| **随机事件 -** | -1 ~ -5 |
| **送材料 / 丹药** | + 5 ~ + 20（按礼物品质） |
| **同行行动** | 按 §4.2 的随机概率变化 |
| **送高价值礼物但失败** | - 10（理解错意） |
| **绝交** | 直接移除 |
| **道友死亡** | - 30（永久） |
| **道友重伤被救** | + 20 |
| **道友重伤未救** | - 10 |

### 3.3 好感度的关键阈值

| 阈值 | 解锁 |
| --- | --- |
| **0（陌生人）** | 仅基础信息 |
| **30（点头之交）** | 显示完整背景 |
| **50（知交）** | 可邀请组队 |
| **70（莫逆）** | 传授丹方 / 功法 |
| **90（至交）** | 触发专属剧情 |
| **100（道侣）** | 后期解锁（详见 [09-分期路线图](./09-分期路线图.md)） |

### 3.4 好感度的 UI 展示

- 道友列表中显示好感度条 + 数值。
- 悬停 / 点击展开历史记录（最近 10 次变化）。
- 阈值达成时弹出"关系升级"提示。

## 4. 组队

### 4.1 选择同行

- 当前一世已结识的任意一位道友均可被设为同行对象；一次最多同行 1 人。
- 玩家可在因缘页随时更换或解除同行对象，不打断正在进行的行动；新选择从下一次行动开始生效。
- 转世后默认不继承同行选择，需要重新选择当世道友。

### 4.2 组队的实际增益

同行对象会持续协助修行、游历与炼丹，直到玩家更换或解除选择：

| 加成 | 数值 |
| --- | --- |
| **灵气收获** | 三类行动结算的灵气均额外 +40% |
| **游历协助** | 30% 概率额外获得 1 份材料 |
| **炼丹协助** | 20% 概率使本次炼丹成功率 +15 个百分点 |
| **新道友相遇** | 游历中偶遇道友概率降低 60%（12% 降至 4.8%） |
| **好感变化** | 每次行动后，35% 概率 +1~3；15% 概率 -1~2；其余不变 |

### 4.3 同行的消耗

- 当前 Demo 不额外消耗玩家或道友寿元；寿元仅随现实时间推进。
- 同行机会会降低新道友相遇率，避免道友数量无节制增长。
- 一次只能选择 1 人同行，MVP 不支持多人同行。

### 4.4 解除同行

- 玩家可随时解除同行或更换对象，新的选择从下一次行动生效。

## 5. 送东西 / 绝交

### 5.1 送东西

- 玩家可以从背包选择材料、丹药送给道友。
- 礼物匹配道友需求（如道友喜欢某灵根材料）时，好感度翻倍。
- 礼物不匹配时，好感度仅 +5（仍可送，但效果弱）。
- 礼物送出后**不可退回**。

### 5.2 绝交

- 玩家可以在道友列表主动绝交。
- 绝交后 NPC 永久移除，所有已解锁的丹方、功法保留（"曾经学过"）。
- 绝交在当前多世存档中不可逆，该魂识不再进入后世重逢池；只有开新游戏后才可能重新出现。

---

## 6. 道友的成长与独立寿元

### 6.1 独立寿元

道友有**自己的寿元**，与玩家寿元**独立计时**。

- 道友寿元到达上限 = 寿终正寝。
- 队友组队会推进道友寿元。
- 玩家当前一世结束时，道友在本世的年龄与状态一并封存到世系记录；若因缘延续，道友会在新一世以新身份重新生成。

### 6.2 道友的成长

道友会按自己的境界自动成长（懒更新）：
- 道友的境界层数缓慢提升（玩家活跃时）。
- 道友也会尝试突破（成功率略低于玩家，有自己的机缘）。

### 6.3 道友的重伤与死亡

| 触发场景 | 概率 |
| --- | --- |
| **冒险中重伤** | 5% / 次（仅当玩家组了该道友） |
| **自发性重伤** | 0.1% / 年（道友自己冒险失败） |
| **寿终正寝** | 寿元到上限 |
| **被高阶修士所杀** | 0.01% / 年（剧情触发） |

> 重伤 = 寿元 -50% 上限（不可逆）。
> 死亡 = 永久移除。

### 6.4 玩家可抢救

道友重伤时，系统弹出提示：

```
[道友 XXX 在 YYY 中重伤，寿元上限减少 N 年]
                          │
                          ▼
            ┌─────────────┴─────────────┐
            ▼                           ▼
       [送丹药抢救]                [不救]
            │                           │
            ▼                           ▼
     消耗玩家丹药 X 颗            道友重伤状态保留
     道友完全康复                下次重伤可能直接死亡
     好感度 + 20
```

- 抢救成功：道友完全恢复，好感度 +20。
- 抢救失败：丹药消耗但道友仍重伤（小幅恢复寿元上限）。
- 不救：道友重伤持续，下次重伤可能直接触发死亡事件。

### 6.5 道友死亡的叙事

道友死亡是**强叙事事件**：
- 弹出大幅提示卡 + 故事文案。
- 自动记录到大事记。
- 玩家失去该道友的所有协作能力。
- 不会自动从本世列表移除（玩家可以选择“放下”或“纪念”）。死亡不阻止其在后世转世重逢。

---

## 7. 转生与道友的继承

详见 [06-转生与多结局 §3](./06-转生与多结局.md)。简述：

- 部分高因缘道友会在转生后**以新身份重新遇到**，姓名、年龄、境界和性格重新生成。
- 已死亡的道友仍可进入转世重逢池；死亡只结束其当前一世。
- 已绝交的道友不进入下一世的重逢池，除非玩家开新游戏。
- 重逢时保留稳定的“魂识 ID”用于关联前世记录，但角色界面不会直接暴露技术字段。

---

## 8. 后续扩展（1.x / 2.x）

- **道侣系统**：好感度 100 后的深度发展（合籍双修、共修洞府）。
- **道友主动交互**：道友会主动找玩家（送礼物 / 邀请组队）。
- **道友阵营**：道友之间可能存在恩怨。
- **道友的死亡叙事扩展**：触发专属剧情线。
