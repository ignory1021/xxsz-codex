# 03 · 探索与文字战斗

本文档定义炼丹主线下的探索、遭遇与调息。详细经济规则见 [09-炼丹主线与经济](./09-炼丹主线与经济.md)。

---

## 1. 探索定位

探索是炼丹材料、战利品与道友相逢的主要来源，不直接提供境界经验。每次玩家手动选择一次地图探索，结算后推进对应寿元天数。

每次探索：

```
[支付路费 + 消耗体力 + 推进寿元天数] → [基础材料] → [文字事件 / 妖物遭遇] → [写入修行历程]
```

普通结果自动记录，不要求确认；遭遇妖物、奇遇和道友相逢才弹出剧情卡。

## 2. 地图进度

- 每张地图有境界准入与推荐攻防；高阶地图需要更高境界，且建议先购买对应装备。
- 境界只决定地图候选和集市装备品级，不保证战斗胜利。
- 地图产出随阶位上升：低阶以基础草药为主，中阶开始需要灵矿与稀有药材，高阶包含关键炼丹素材；木灵根提高材料发现概率与单次采集数量。
- 基础地图探索消耗 **30 ± 10 天**，高阶地图探索消耗 **90 ± 30 天**；中间地图的行动天数在数值表中补齐。

## 3. 妖物遭遇

### 3.1 交互

遭遇卡展示妖物、地点和危险描述，玩家选择“迎战”或“退避”。不做回合制、技能栏或手动攻击。

### 3.2 自动判定

- 玩家攻击由境界、金灵根、武器与饰物决定；玩家防御由境界、土灵根、防具与饰物决定；水灵根提供生命上限。
- 妖物有攻击、防御与危险等级；系统按双方攻防进行一次胜负判定。
- 迎战胜利获得额外材料、战利品或灵石；战败会损失生命，只能保留部分基础收益，并可能遗失部分当次所得。
- 退避不触发战败惩罚，但放弃额外战利品。

判定具体公式与各地图妖物数值在实现前统一确认，不作为隐藏机制。

## 4. 体力、灵石与调息

- 探索消耗体力、路费与寿元天数；任一不足时无法开始。
- 调息消耗寿元天数，恢复体力与精力，但不提供主要境界经验。
- 玩家也可以在集市购买食物、灵饮等恢复品；系统不会自行购买，避免无感消耗灵石。

## 5. 道友与奇遇

- 道友主要在探索事件中相逢；保留文字剧情、好感度与转世重逢。
- 奇遇可提供材料、折扣、临时攻防或炼丹辅助，但选项不展示结果数值。
- 道友对探索和炼丹的具体协助效果需在经济与战斗数值确定后重设，旧版“灵气加成”不再适用。

## 6. MVP 边界

- 保留单次探索、地图选择、剧情卡、文字战斗、地图准入与装备推荐。
- 不做回合制、技能树、敌人立绘、完整掉落词条或地图可视化。
- 移除暂停、时间倍率与离线推进；保留修行历程。
