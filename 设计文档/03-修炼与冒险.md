# 03 · 探索与文字战斗

本文档定义炼丹主线下的探索、遭遇与调息。详细经济规则见 [09-炼丹主线与经济](./09-炼丹主线与经济.md)。

---

## 1. 探索定位

探索是炼丹材料、战利品与道友相逢的主要来源，不直接提供境界经验。每次玩家手动选择一次地图探索，结算后推进对应寿元天数。

每次探索：

```
[支付路费 + 消耗体力 + 推进寿元天数] → [基础材料] → [文字事件 / 妖物遭遇] → [写入修行历程]
```

普通结果自动记录，不要求确认；遭遇妖物、奇遇和道友相逢才弹出剧情卡。

## 2. 地图进度

- 每张地图有境界准入与推荐攻防；高阶地图需要更高境界，且建议先购买对应装备。
- 境界只决定地图候选和集市装备品级，不保证战斗胜利。
- 地图产出随阶位上升：低阶以基础草药为主，中阶开始需要灵矿与稀有药材，高阶包含关键炼丹素材；木灵根提高材料发现概率与单次采集数量。
- 基础地图探索消耗 **30 ± 10 天**，高阶地图探索消耗 **90 ± 30 天**；中间地图的行动天数在数值表中补齐。

### 2.1 单次探索的事件判定（MVP）

先结算地图保底材料与木灵根的额外掉落，再进入一次且仅一次事件判定。没有同行时，事件区间依次为：道友相逢 10%、妖物遭遇 30%、额外采集 15%、游商 10%、遗府 10%、平静归返 25%；有同行时，道友相逢率改为 4%，其余事件区间依次为 30%、15%、10%、10%、31%。道友池已达 MVP 上限时，其区间直接改为平静归返。

| 事件 | 玩家选择与公开结算 | 数值结果 |
| --- | --- | --- |
| 道友相逢 | 进入三选项剧情卡 | 按 [05-道友系统](./05-道友系统.md) 结识或错过道友 |
| 妖物遭遇 | 迎战或退避 | 按 §3 自动结算 |
| 额外采集 | 自动结算，不弹窗 | 在当前地图三种基础材料中等概率获得 1 份 |
| 游商 | 支付本地图一次路费，或离开 | 支付后由玩家在当前地图三种基础材料中任选 1 种，获得 2 份；不自动购买 |
| 遗府 | 探索或离开 | 探索有 70% 概率获得 1 份妖物额外掉落材料（等概率三选一），30% 概率损失当前生命上限的 20%，当前生命最低保留 1 点 |
| 平静归返 | 自动结算，不弹窗 | 无额外变化 |

事件剧情只描述已发生的结果；事件选项事前不展示概率、数值或好感变化。事件不会额外推进寿元，也不连续触发第二个事件。

## 3. 妖物遭遇

### 3.1 交互

遭遇卡展示妖物、地点和危险描述，玩家选择“迎战”或“退避”。不做回合制、技能栏或手动攻击。

### 3.2 自动判定

- 玩家攻击由境界、金灵根、武器与饰物决定；玩家防御由境界、土灵根、防具与饰物决定；水灵根提供生命上限。
- 妖物有攻击、防御与危险等级；系统按双方攻防进行一次胜负判定。
- 迎战胜利按固定掉落表获得额外材料或灵石；战败生命降至 1，保留本次所有已结算的地图保底材料，但失去妖物额外战利品并有概率获得轻伤。
- 退避不触发战败惩罚，但放弃额外战利品。

判定具体公式与各地图妖物数值见 [10-MVP 数值草案](./10-MVP数值草案.md)，经审核确认后才进入实现，不作为隐藏机制。

## 4. 体力、灵石与调息

- 探索消耗体力、路费与寿元天数；任一不足时无法开始。
- 调息消耗寿元天数，恢复体力与精力，但不提供主要境界经验。
- 玩家也可以在集市购买食物、灵饮等恢复品；系统不会自行购买，避免无感消耗灵石。

## 5. 道友与奇遇

- 道友主要在探索事件中相逢；保留文字剧情、好感度与转世重逢。
- MVP 奇遇限定为额外采集、游商与遗府三种机制，所有结果见 §2.1；每种机制可配置多段叙事文本，但不得新增未公开的数值效果。
- 道友对探索和炼丹的具体协助效果采用 [10-MVP 数值草案](./10-MVP数值草案.md) §7.2，不再使用旧版“灵气加成”。

## 6. MVP 边界

- 保留单次探索、地图选择、剧情卡、迎战/退避与一次自动战斗结算、地图准入与装备推荐。
- 不做回合制、技能树、敌人立绘、完整掉落词条或地图可视化；这些属于 1.0 的完整战斗扩展。
- 移除暂停、时间倍率与离线推进；保留修行历程。
