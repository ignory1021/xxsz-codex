# 03 · 修炼与冒险

本文档定义 **修炼** 和 **冒险** 两个核心行为的机制。炼丹体系单独写在 [04-炼丹系统](./04-炼丹系统.md)。

---

## 1. 修炼

### 1.1 定位

**主线行为**。提供稳定的灵气增长，是境界层数提升的主要来源。

### 1.2 交互流程

```
[选择修炼难度]  ──►  [自动计划持续修炼]  ──►  [进度条几秒]
       ▲                                                   │
       │                                                   ▼
       └──────────────────── [修炼历程记录结算] ◄──── [灵气 + 可能心境事件]
```

难度选择即设为当前计划；岁序运行时无需再提交，结算后会自动继续。玩家改选游历、炼丹或另一难度时，从当前一次修炼结束后切换。

### 1.3 难度分层

按境界解锁：

| 境界 | 可选难度 |
| --- | --- |
| 练气 | 轻、中 |
| 筑基 | 轻、中、重 |
| 金丹 | 轻、中、重、超 |
| 元婴 及以上 | 全部 |

难度参数（建议）：

| 难度 | 额外推进寿元 | 基础灵气产出 |
| --- | --- | --- |
| 轻 | 1 月 | 10 |
| 中 | 1 季（3 月） | 40 |
| 重 | 1 年 | 200 |
| 超 | 5 年 | 1,200 |

> 超难度只在高境界解锁，提供"快进"通道，但寿元压力大。

### 1.4 灵根系数应用

实际灵气产出 = 难度基础灵气 × 灵根结构加成 × 资质加成 × 状态加成

> 例：练气 1 层，玩家双灵根上品（×1.2 × 1.5 = ×1.8），选择中难度
> 灵气 = 40 × 1.8 = 72 灵气 / 季（无其他状态加成时）

### 1.5 奇遇抉择（修炼副产物）

每次修炼结算有 **8%** 概率触发“灵光乍现”奇遇。奇遇会暂停自动计划并弹出剧情卡，玩家选择后自动恢复原计划；普通修炼结算不弹窗。

| 选项 | 效果 |
| --- | --- |
| **静观石刻** | 获得基础灵气 +60（受灵根加成），悟性 +1（当前一世有效） |
| **破禁探幽** | 55% 概率获得基础灵气 +140（受灵根加成），45% 概率额外消耗 6 个月寿元 |
| **收敛离去** | 无数值变化，记录该次选择 |

## 2. 冒险

### 2.1 定位

**辅助行为**。产出材料、触发随机事件（识友、奇遇、危难）。是材料的主要来源。
冒险完成时也可以获得灵气（低于修炼获得的灵气值）。


### 2.2 形式：**大地图随机游走**

- 玩家从**当前境界解锁的地图列表**中选择一个地图进入。
- 进入后，角色在地图上"游走"，每走一段就可能触发事件。
- 没有可视化大地图（MVP 阶段），而是**文字描述 + 事件卡片流**："你走入山谷深处，发现……"。

### 2.3 地图解锁表

| 境界 | 解锁地图 | 主要产出 |
| --- | --- | --- |
| 练气 | 山谷、溪畔、林间 | 凡品材料（草药、矿石）、初识道友 |
| 筑基 | 古洞、迷雾岭、幽潭 | 中品材料、奇遇 |
| 金丹 | 火山、深渊、雪山 | 中品~上品材料、识友、灵兽 |
| 元婴 | 秘境、星辰海 | 上品材料、机缘 |
| 化神 | 仙府遗址 | 极品材料、古功法残页 |
| 炼虚 | 天外天 | 飞升相关材料 |
| 合体 | 虚空中 | 仙材 |
| 大乘 | 神域边缘 | 神级材料 |
| 渡劫 | 雷海 | 渡劫相关 |

> 每个地图都有独特的事件池和材料池，境界越高地图产出的材料品质越高。

### 2.4 冒险交互流程

```
[选择地图]  ──►  [选择冒险难度]  ──►  [自动游历计划]  ──►  [进度条几秒]
                                                           │
                                                           ▼
                                          [结算：可能触发剧情抉择]
                                                           │
                                                           ▼
                              [普通结算写入修炼历程，自动继续下一次游历]
```

### 2.5 难度分层

| 难度 | 寿元消耗 | 事件数 | 收益 |
| --- | --- | --- | --- |
| 轻 | 1 月 | 1 | 1 种凡品材料 |
| 中 | 1 季 | 1 ~ 2 | 1 ~ 2 种凡品~中品材料 |
| 重 | 1 年 | 2 ~ 3 | 2 ~ 3 种中品~上品材料，可能识友 |
| 超 | 5 年 | 3+ | 极品材料，可能识高阶道友 / 触发重大事件 |

### 2.6 冒险中的随机事件类型

| 类型 | 概率 | 效果 |
| --- | --- | --- |
| **材料发现** | 50% | 获得材料 |
| **偶遇道友** | 12% | 弹出相逢剧情并由玩家决定结交方式（详见 [05-道友系统](./05-道友系统.md)） |
| **与敌遭遇** | 20% | 纯文字战斗描述（详见下） |
| **奇遇 / 机缘** | 12% | 弹出剧情并由玩家选择增益、风险或离去 |
| **陷阱** | 8% | 损耗寿元 / 损失材料 |
| **无事发生** | 2% | 仅推进寿元，无产出 |

### 2.7 轻量遭遇判定（MVP）

**保留遭遇选择与一次性结果判定，不做完整战斗系统**。

- 遭遇战是文字事件，玩家只能通过选择"逃 / 战 / 谈判"应对。
- “战”选项只按境界对比和事件修正进行一次性判定，不引入战力、回合、技能或装备数值。
- 战斗胜负影响寿元损耗（败则寿元 -1 年），但不会直接死亡（除非寿元已近耗尽）。

> 完整数值战斗留给 [09-分期路线图](./09-分期路线图.md) 的 1.0 版本。

## 3. 难度选择机制

用户提到的"主动选择 + 随机分配"机制，落地为：

### 3.1 主动选择

- UI 显式列出可选难度；点击难度即更新当前自动行为计划。
- 玩家可以查看每个难度的寿元消耗与预期收益。
- 推荐按钮：根据玩家当前寿元、目标进度推荐一个。

### 3.2 随机分配

- 玩家可以勾选"随机"按钮，让游戏按以下规则分配难度：
  - 每次提交时按权重随机一个难度（轻:中:重:超 = 5:3:1.5:0.5）。
  - 连续 2 次"超难度"必出 1 次"轻难度"（保护机制）。
  - 玩家随时可以取消勾选回到主动选择。

### 3.3 设计意图

- 主动选择给控制感。
- 随机分配给"懒人玩家"一个合理默认值，避免一直点最低难度让游戏变慢。
- 推荐按钮给新手引导。

## 4. 行为与寿元的耦合

### 4.1 寿元保护

- 任何行为在提交前若发现寿元不足，弹出警告"寿元不足以支撑这次 XX，是否继续？"
- 若行为成本会使当前年龄达到寿元上限，弹出“此行或至寿尽”二次确认。
- 玩家确认后仍可执行；年龄达到上限时立即进入死亡结算，未完成行为按中断处理（详见 [06-转生与多结局](./06-转生与多结局.md)）。

### 4.2 寿元的经济循环

```
境界 ↑  ──►  寿元上限 ↑
   ▲                  │
   │                  ▼
   │           解锁更多高难度
   │                  │
   └──── 收益 ↑ ◄─────┘
```

这是一个**正向循环**：境界越高 → 寿元越多 → 解锁的难度越多 → 单次收益越大 → 升级越快。

通过灵根资质系数拉开玩家差距，让"低灵根 + 高境界"和"高灵根 + 低境界"各有玩法路线。
