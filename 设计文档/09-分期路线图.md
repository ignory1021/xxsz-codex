# 09 · 分期路线图

本文档定义游戏从 MVP 到长期演进的路线图。

---

## 1. 分期总览

| 分期 | 名称 | 目标 | 平台 |
| --- | --- | --- | --- |
| **MVP** | 最小可玩版本 | 验证核心循环与节奏 | 手机网页 |
| **1.0** | 完整循环版 | 补全所有核心系统 | 手机网页 |
| **1.x** | 内容扩展版 | 增加宗门、道侣、战斗 | 手机网页 + 安卓 APK |
| **2.0** | 深度叙事版 | 多分支剧情 + 完整世界观 | 安卓 APK |
| **2.x** | 长期运营 | 持续内容更新、跨端存档 | 安卓 + iOS（可选） |

---

## 2. MVP（当前阶段）

### 2.1 目标

让玩家可以：
1. 创建角色（姓名 / 性别 / 性格 / 灵根）。
2. 通过修炼 / 冒险 / 炼丹提升境界。
3. 识友、好感度、组队、绝交、抢救道友。
4. 突破境界（失败跌落 + 重伤）。
5. 寿元耗尽转生 / 渡劫飞升。
6. 多世游玩 + 记录档。
7. 离线挂机 + 暂停 / 推进。

### 2.2 MVP 必须做

| 系统 | 范围 |
| --- | --- |
| 角色创建 | 姓名、性别、性格、随机灵根（5 种 + 天灵根 / 变异） |
| 修炼 | 4 个难度，灵根系数生效 |
| 冒险 | 9 张地图，纯文字事件，无战斗 |
| 炼丹 | 30+ 材料 + 20~30 丹方 |
| 道友 | 30~50 NPC，识别 + 好感度 + 组队 + 死亡 |
| 境界 | 练气~飞升全境界（10 层 + 大圆满 + 突破） |
| 突破 | 失败随机跌落 + 重伤 |
| 转生 | 继承硬资质 + 部分道友 |
| 飞升 | 8 种结局 |
| 世系 | 多世记录档 |
| 离线挂机 | 衰减 + 上限 |
| 时间流控制 | 暂停 / 推进 / 挂机 |
| 大事记 | 关键节点记录 |
| 存档 | localStorage |
| UI | 浅色古风 + 移动端响应式 |

### 2.3 MVP 不做

| 系统 | 推迟到 |
| --- | --- |
| 战斗系统 | 1.0 |
| 宗门系统 | 1.x |
| 道侣系统 | 1.x |
| 完整功法 / 技能 | 1.x |
| 地图可视化 | 2.0 |
| 主线剧情 | 2.0 |
| 云存档 | 2.x |
| 暗色模式 | 1.x |

### 2.4 MVP 的内容规模（建议）

| 项 | 数量 |
| --- | --- |
| 灵根种类 | 5 + 1 天 + 4 变异 |
| 性格 | 5 ~ 8 种 |
| 地图 | 9 张（MVP 覆盖所有境界） |
| 材料 | 30 种 |
| 丹方 | 25 种 |
| 丹药 | 12 种 |
| 道友 NPC | 30 ~ 50 |
| 境界 | 10（大境界）+ 10 层 × 10 |
| 结局 | 8 种 |
| 诗文 / 文案 | 100~200 段 |

## 3. 1.0（完整循环版）

### 3.1 目标

在 MVP 基础上补全核心系统，正式上线。

### 3.2 主要新增

| 系统 | 说明 |
| --- | --- |
| **战斗系统** | 纯文字遭遇战 + 简单数值判定 |
| **功法系统** | 每个境界解锁默认功法，可学习其他功法 |
| **宗门雏形** | 仅可加入一个宗门，享受简单加成 |
| **暗色模式** | 古风夜晚配色 |
| **音效** | 古风配乐 + 行为音效（可关闭） |
| **更丰富的事件** | 200+ 随机事件池 |
| **云存档（可选）** | 用户可注册账号开启 |

### 3.3 战斗系统设计要点

- 主体仍是**纯文字遭遇战**。
- 玩家有"战力"数值（受境界 + 灵根 + 功法 + 组队道友影响）。
- 战斗是**自动判定**，玩家无法操控细节。
- 战斗结果是材料 / 经验 / 寿元损耗。

## 4. 1.x（内容扩展版）

### 4.1 目标

扩展可玩内容，提升长期留存。

### 4.2 主要新增

| 系统 | 说明 |
| --- | --- |
| **宗门完整版** | 加入 / 退出 / 任务 / 同门 / 宗门战 |
| **道侣系统** | 好感度 100 后解锁，合籍双修 |
| **更多道友** | 50 → 100+ NPC |
| **更多丹方** | 25 → 50 |
| **丹道流派** | 玩家可选专精 + 加成 |
| **节庆事件** | 节日限定的奇遇 / 丹方 |
| **安卓 APK** | 把网页打包成 APK（用 Capacitor / Cordova） |

### 4.3 宗门完整版设计要点

- 玩家可加入 / 退出宗门。
- 宗门提供稳定加成（修炼效率 + X%）。
- 宗门任务 = 限时冒险 + 特殊奖励。
- 同门道友可借阅丹方、协助突破。
- 宗门战（后期）= 跨玩家对抗（云存档版）。

## 5. 2.0（深度叙事版）

### 5.1 目标

引入主线剧情与多分支结局，从"放置游戏"升级为"修仙叙事游戏"。

### 5.2 主要新增

| 系统 | 说明 |
| --- | --- |
| **主线剧情** | 修真界大背景下的多线剧情 |
| **多分支结局** | 基于玩家选择触发的不同结局 |
| **地图可视化** | 大地图、节点、势力范围 |
| **完整功法 / 技能树** | 多套功法路线 |
| **炼器 / 阵道** | 炼丹之外的修真副职业 |
| **NPC 行为深化** | 道友有独立目标、动机 |
| **世界事件** | 全服级别的随机事件（云存档版） |

### 5.3 剧情结构（建议）

- **第一章**：入门（练气~筑基）—— 初识道友、入门宗门。
- **第二章**：成长（筑基~金丹）—— 宗门内斗、势力选择。
- **第三章**：抉择（金丹~元婴）—— 宗门大战、阵营分化。
- **第四章**：飞升（元婴~渡劫）—— 修真界大事、飞升路线分歧。
- **多结局**：根据前几章的选择 + 修为，决定飞升结局。

## 8. 风险与对策

### 8.1 内容产能风险

修仙游戏内容（事件、文案、丹方）多，依赖作者。

**对策**：
- 建立"事件模板库"，用变量填充产出不同事件。
- 文案以"短句组合"为主，减少单段文案长度。
- 玩家在长期游玩中"重复遇到"相似事件是可接受的。

### 8.2 数值平衡风险

多世游玩后数值可能失控（悟性无限累计等）。

**对策**：
- 悟性有上限（如 100）。
- 转生时悟道点有上限（多世累计）。
- 高境界后悟性边际收益递减。

### 8.3 留存风险

单世寿命有限，玩家可能快速通关。

**对策**：
- 1.x 引入宗门、节庆事件。
- 2.0 引入大轮回系统（多世累计触发新内容）。
- 2.x 引入跨玩家社交，让"道友"成为长期情感锚点。

## 9. 下一步建议

完成 MVP 设计文档后，建议的开发顺序：

1. **搭建基础框架**：存档、时间流、UI 骨架。
2. **实现角色创建 + 修炼**：验证基础循环。
3. **加入境界与突破**：建立核心进度感。
4. **加入冒险 + 炼丹**：补全三大行为。
5. **加入道友**：增加社交深度。
6. **加入转生 + 多结局**：完成单世闭环。
7. **加入离线挂机 + 大事记**：完成 MVP 全部功能。
8. **调优数值与文案**：打磨节奏与风格。
9. **发布 MVP + 收集反馈**。
10. **进入 1.0 规划**。

> MVP 完成前，不要急于加战斗、宗门等系统。先把核心循环打磨到玩家愿意"再开一世的程度"。
