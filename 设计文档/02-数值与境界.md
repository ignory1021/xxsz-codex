# 02 · 数值与境界

本文档定义游戏的核心数值体系：**寿元、灵根、境界分层、突破**。

> 数值表中的数字均为**初始建议值**，实现时需要在测试中调优。

---

## 1. 寿元

### 1.1 基础规则

- **上限**：角色寿元的最大值。寿元到达上限 = 死亡 = 转生。
- **当前**：角色当前已活到的年龄。仅在探索、炼丹、调息等行动结算时推进。
- **行为消耗寿元**：每次行动按其档位在天数区间内随机推进；基础行动为 20 ~ 40 天，高阶行动为 60 ~ 120 天。
- **存储单位**：年龄、寿元上限和行动成本统一换算为整数天；1 年 = 360 天，1 月 = 30 天。
- **结算顺序**：先结算行动所得、丹道经验与由升级带来的寿元上限，再推进本次随机天数；即使剩余寿元不足，本次行动也允许开始并在结算后判定死亡。

### 1.2 各境界寿元上限与层数增益（MVP）

> 玩家期望：不吃丹药、不刻意延寿，到飞升前自然寿命约 **900 年**。

| 境界 | 1 层寿元上限 | 每提升一层 | 备注 |
| --- | --- | --- | --- |
| 练气 | 50 年 | +1 年 | 凡人寿命|
| 筑基 | 60 年 | +2 年 | 长一些 |
| 金丹 | 80 年 | +3 年 | 真正跨入"修真者" |
| 元婴 | 110 年 | +4 年 | |
| 化神 | 150 年 | +5 年 | |
| 炼虚 | 200 年 | +10 年 | |
| 合体 | 300 年 | +15 年 | |
| 大乘 | 450 年 | +20 年 | |
| 渡劫 | 650 年 | +25 年 | 十层约 900 年 |
| 飞升 | — | — | 飞升即结局，不计寿元上限 |

> 每次小层与大境界提升都只提高寿元上限，不重置当前已推进的寿元值，如已推进 80 / 上限 300。渡劫十层的寿元上限约为 900 年，符合当前 MVP 目标。
> 寿元不再对应现实时间；练气期可执行的行动次数取决于行动天数、境界提升与延寿效果。

### 1.3 寿元的其他来源

- **丹药**： 清心丹、续命丹等（详见 [04-炼丹系统](./04-炼丹系统.md)）。
- **机缘**：随机事件中偶发延寿（如"得一株千年灵芝"）。
- **功法**（后期）：部分特殊功法有延寿效果。

## 2. 灵根

### 2.1 五行构成

角色灵根由固定的 **金、木、水、火、土** 五项根值构成。当前版本不再以“天灵根”“杂灵根”等分类直接决定强弱，而是以完整的五行分布决定角色的属性倾向。

### 2.2 五行根值与派生属性

角色拥有金、木、水、火、土五项独立的灵根强度。创建角色时随机生成一份五行分布；每一项的高低直接决定对应派生属性的基础表现，而不再只计算一个综合修炼倍率。

| 灵根 | 主要派生属性 | 游戏影响 |
| --- | --- | --- |
| **火灵根** | 炼丹成功率、丹道经验 | 提高成丹把握，并提高成功炼丹所得的丹道经验 |
| **土灵根** | 防御 | 提高文字战斗中的防御能力，减少受创与战败风险 |
| **金灵根** | 攻击 | 提高文字战斗中的攻击能力，提升迎战胜率 |
| **木灵根** | 采集 | 提高探索发现材料的概率，并提高材料数量 |
| **水灵根** | 生命 | 提高生命上限，提升战斗中的承伤空间 |

- 五行根值展示在角色卡上，并同时展示由其计算出的炼丹、攻击、防御、采集与生命属性。
- 装备提供额外攻击、防御或探索辅助；装备加成与灵根派生属性叠加。
- 灵根只提供路线倾向，不应单独决定胜负或完全取代装备、经济与行动选择。

### 2.3 层级成长

每次境界层级提升后，五行根值对对应派生属性的影响同步提高。高境界修士会比低境界时更能发挥先天灵根；首版公式与根值生成规则见 [10-MVP 数值草案](./10-MVP数值草案.md)，经审核后才进入实现。

### 2.4 灵根调整

**净灵丹**等丹药可以调整当前一世的五行根值，但不会改变转世时的重新随机规则。

- 灵根调整的上限、边际收益与是否消耗寿元，均在丹方数值表中公开说明。
- 当前一世的灵根调整不作为跨世继承项。

### 2.5 灵根生成与转生

- 每一世创建角色时，均独立随机生成新的五行灵根分布。
- 转世不参考上一世的灵根种类、根值、净化效果或任何灵根相关加成。
- 前世灵根仅保留在世系记录档中，作为叙事记录，不提供隐藏数值加成。

## 3. 境界体系

### 3.1 完整境界列表

```
练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升
```

每个境界分 **10 层 + 大圆满**，大圆满后可尝试**突破**到下一境界。

每次从第 N 层提升至第 N+1 层，立即获得本境界的“每提升一层”寿元上限增益；进入下一大境界后改用新境界的基础上限与层数增益。

境界表示方法：

```
练气 1 层
练气 2 层
...
练气 10 层
练气大圆满  ← 用户手动触发突破
```

### 3.2 境界层数与丹道经验

境界层数提升靠 **累积丹道经验**，主要由成功炼丹获得；探索、装备与经济循环用于取得更高阶炼丹所需的材料与条件。

建议丹道经验需求曲线（每个境界 1~10 层 + 大圆满）：

| 境界 | 1→2 层 | 9→10 层 | 10→大圆满 |
| --- | --- | --- | --- |
| 练气 | 100 | 300 | 500 |
| 筑基 | 500 | 1,500 | 2,500 |
| 金丹 | 2,500 | 6,500 | 12,500 |
| 元婴 | 12,500 | 32,500 | 62,500 |
| 化神 | 60,000 | 150,000 | 300,000 |
| 炼虚 | 300,000 | 900,000 | 1,500,000 |
| 合体 | 1,500,000 | 3,500,000 | 7,500,000 |
| 大乘 | 7,500,000 | 22,500,000 | 40,000,000 |
| 渡劫 | 40,000,000 | 100,000,000 | 200,000,000 |

> 每一级是上一级的 ~5 倍，符合"境界越高越慢"的预期。

## 4. 突破机制

### 4.1 触发条件

- 角色处于"XX 大圆满"状态。
- 当前寿元未耗尽。
- 满足某些前置条件（详见各境界设定）。
- 达到大圆满后立即展示突破入口；不存在自动计划、自动续行或现实时间推进。

### 4.2 突破成功率（建议）

服用破境类丹药后，其成功率加成会叠加到下一次突破判定；无论该次突破成功或失败，加成均会在结算后清空。

基础成功率随境界提升而下降：

| 境界 | 基础成功率 |
| --- | --- |
| 练气 → 筑基 | 90% |
| 筑基 → 金丹 | 75% |
| 金丹 → 元婴 | 60% |
| 元婴 → 化神 | 45% |
| 化神 → 炼虚 | 30% |
| 炼虚 → 合体 | 20% |
| 合体 → 大乘 | 15% |
| 大乘 → 渡劫 | 10% |
| 渡劫 → 飞升 | 5%（另见 [06-转生与多结局](./06-转生与多结局.md)） |

### 4.3 成功率的影响因素

| 因素 | 影响 |
| --- | --- |
| **丹药（破境丹）** | + 5% ~ + 30%（按丹药品级） |
| **心魔 / 执念** | - 5% ~ - 20%（高境界偶发） |
| **随机事件** | ±5%（罕见） |
| **道友协助**（后期） | + 5% ~ + 15% |

### 4.4 失败后果

**随机跌落 + 重伤**（用户决定）。

- 跌落：随机下降 **1 ~ 3 层**（大圆满跌至 9 / 8 / 7 层）。
- 重伤：获得负面状态"重伤"，持续到下一次成功大圆满，期间所有行为效率降低 30%。

> 重伤不可被玩家取消（除特定丹药），提供决策深度。

### 4.5 突破成功

- 进入下一境界 1 层。
- 寿元上限按新境界的基础值与层级规则重新计算（具体数值见 §1.2）。
- 解锁新地图（冒险）。
- 解锁新丹方。
- 可能触发"飞升异象"等叙事事件。

## 5. 灵根与境界的耦合

境界与层级越高，五行灵根对派生属性的影响越明显：

- **练气期**：灵根决定初期的炼丹、采集与战斗倾向。
- **金丹期**：灵根与装备共同决定能否稳定应对高阶地图与丹方。
- **化神期以上**：高根值五行可解锁专属丹道、装备或探索事件。

这一耦合保证灵根不仅是初期优势，也是长期养成的核心。
