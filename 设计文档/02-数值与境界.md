# 02 · 数值与境界

本文档定义游戏的核心数值体系：**寿元、灵根、境界分层、突破**。

> 数值表中的数字均为**初始建议值**，实现时需要在测试中调优。

---

## 1. 寿元

### 1.1 基础规则

- **上限**：角色寿元的最大值。寿元到达上限 = 死亡 = 转生。
- **当前**：角色当前已活到的年龄。每次行为都会推进当前寿元。
- **消耗 = 推进**：每次修炼 / 冒险 / 炼丹都会按行为的"难度"消耗一定寿元，**本质上是让时间向前推进**。

### 1.2 各境界寿元上限（建议）

> 玩家期望：不吃丹药、不刻意延寿，到飞升前自然寿命约 **一万年** 左右。

| 境界 | 寿元上限 | 备注 |
| --- | --- | --- |
| 练气 | 70 年 | 凡人寿命稍延长 |
| 筑基 | 150 年 | 长一些 |
| 金丹 | 300 年 | 真正跨入"修真者" |
| 元婴 | 500 年 | |
| 化神 | 1,000 年 | |
| 炼虚 | 2,000 年 | |
| 合体 | 3,500 年 | |
| 大乘 | 5,500 年 | |
| 渡劫 | 8,000 年 | |
| 飞升 | — | 飞升即结局，不计寿元上限 |

> 每次升境界只提升寿元上限，不重置当前已推进的寿元值，如 已推进80/上限300。考虑到可能有寿元延寿丹以及突破失败，落地在 **一万年** 量级，符合用户预期。

### 1.3 寿元的其他来源

- **丹药**：延寿丹、续命丹等（详见 [04-炼丹系统](./04-炼丹系统.md)）。
- **机缘**：随机事件中偶发延寿（如"得一株千年灵芝"）。
- **功法**（后期）：部分特殊功法有延寿效果。

## 2. 灵根

### 2.1 灵根类型

五行固定：**金、木、水、火、土**。

特殊灵根（在随机生成时低概率出现）：
- **天灵根**：单一属性，资质极高。
- **变异灵根**：两种属性融合（如水木融合为"木灵根"，火金融合为"雷灵根"等），兼具特殊效果。
- **伪灵根**：三种及以下属性，但每个属性浓度都很低（资质低），代表普通资质。
- **五行杂灵根**：五种属性齐全但都极淡，最差开局。

### 2.2 灵根的两个维度

| 维度 | 含义 | 取值范围 |
| --- | --- | --- |
| **个数（属性种类数）** | 主角具备几种五行属性 | 1（天灵根）~ 5（杂灵根） |
| **资质（单属性浓度）** | 每个属性的浓度 | 1（极低）~ 10（极纯） |

### 2.3 灵根与修炼收益的关系

**灵根个数 × 资质 = 收益系数（乘法关系）**。

```
修炼收益 = 基础灵气 × (灵根个数加成) × (资质加成)
```

具体公式（建议）：

| 灵根个数 | 加成 |
| --- | --- |
| 1（天灵根） | × 1.5 |
| 2 | × 1.2 |
| 3 | × 1.0 |
| 4 | × 0.75 |
| 5（杂灵根） | × 0.5 |

| 平均资质 | 加成 |
| --- | --- |
| 1 ~ 3（凡品） | × 0.5 |
| 4 ~ 6（中品） | × 1.0 |
| 7 ~ 8（上品） | × 1.5 |
| 9 ~ 10（极品 / 天灵根） | × 2.0 |

> 综合算下来：
> - 天灵根极品（个数 ×1.5，资质 ×2.0）= ×3.0
> - 双灵根上品（×1.2 × 1.5）= ×1.8
> - 五行杂灵根凡品（×0.5 × 0.5）= ×0.25
>
> 差距达到 12 倍，足以让天灵根玩家明显快、杂灵根玩家明显慢，鼓励后期靠丹药追平。

### 2.4 灵根净化

**净灵丹**可以提升灵根的资质（单属性浓度），但不改变灵根个数。

- 净灵丹对低资质灵根的提升幅度更大（边际收益递减）。
- 资质上限 10，天灵根无法被进一步提升（已是极品）。
- 每次净化需要消耗寿元（药力渗入经脉）。

### 2.5 转生时灵根的继承

- 灵根**类型**与**资质**会被转生继承（永久）。
- 玩家可以选择转生后是否重新洗灵根（消耗前世积累的"悟道点"随机一次），洗后保留高资质但可能改变个数。

## 3. 境界体系

### 3.1 完整境界列表

```
练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升
```

每个境界分 **10 层 + 大圆满**，大圆满后可尝试**突破**到下一境界。

境界表示方法：

```
练气 1 层
练气 2 层
...
练气 10 层
练气大圆满  ← 用户手动触发突破
```

### 3.2 境界层数与灵气

境界层数提升靠 **累积灵气**，每次修炼会按难度与灵根系数产出灵气。

建议灵气需求曲线（每个境界 1~10 层 + 大圆满）：

| 境界 | 1→2 层 | 9→10 层 | 10→大圆满 |
| --- | --- | --- | --- |
| 练气 | 100 | 300 | 500 |
| 筑基 | 500 | 1,500 | 2,500 |
| 金丹 | 2,500 | 6,500 | 12,500 |
| 元婴 | 12,500 | 32,500 | 62,500 |
| 化神 | 60,000 | 150,000 | 300,000 |
| 炼虚 | 300,000 | 900,000 | 1,500,000 |
| 合体 | 1,500,000 | 3,500,000 | 7,500,000 |
| 大乘 | 7,500,000 | 22,500,000 | 40,000,000 |
| 渡劫 | 40,000,000 | 100,000,000 | 200,000,000 |

> 每一级是上一级的 ~5 倍，符合"境界越高越慢"的预期。

## 4. 突破机制

### 4.1 触发条件

- 角色处于"XX 大圆满"状态。
- 当前寿元未耗尽。
- 满足某些前置条件（详见各境界设定）。

### 4.2 突破成功率（建议）

基础成功率随境界提升而下降：

| 境界 | 基础成功率 |
| --- | --- |
| 练气 → 筑基 | 90% |
| 筑基 → 金丹 | 75% |
| 金丹 → 元婴 | 60% |
| 元婴 → 化神 | 45% |
| 化神 → 炼虚 | 30% |
| 炼虚 → 合体 | 20% |
| 合体 → 大乘 | 15% |
| 大乘 → 渡劫 | 10% |
| 渡劫 → 飞升 | 5%（另见 [06-转生与多结局](./06-转生与多结局.md)） |

### 4.3 成功率的影响因素

| 因素 | 影响 |
| --- | --- |
| **丹药（破境丹）** | + 5% ~ + 30%（按丹药品级） |
| **心魔 / 执念** | - 5% ~ - 20%（高境界偶发） |
| **随机事件** | ±5%（罕见） |
| **角色悟性** | + 1% ~ + 10%（永久累计） |
| **道友协助**（后期） | + 5% ~ + 15% |

### 4.4 失败后果

**随机跌落 + 重伤**（用户决定）。

- 跌落：随机下降 **1 ~ 3 层**（大圆满跌至 9 / 8 / 7 层）。
- 重伤：获得负面状态"重伤"，持续到下一次成功大圆满，期间所有行为效率降低 30%。

> 重伤不可被玩家取消（除特定丹药），提供决策深度。

### 4.5 突破成功

- 进入下一境界 1 层。
- 寿元上限提升（如从 30 年 → 50 年）。
- 解锁新地图（冒险）。
- 解锁新丹方。
- 可能触发"飞升异象"等叙事事件。

---

## 5. 灵根与境界的耦合

境界越高，灵根的边际收益越高：

- **练气期**：灵根资质主要影响灵气增长速率，差距在 3 倍内。
- **金丹期**：灵根决定能否突破某些高阶丹方。
- **化神期以上**：变异灵根解锁专属功法（如雷灵根可练雷法）。

这一耦合保证灵根不仅是初期优势，也是长期养成的核心。
