# 04 · 炼丹系统

本文档定义炼丹体系的材料、丹方与丹药。

---

## 1. 体系定位

炼丹是 **材料 → 丹药** 的转化器，丹药反哺修炼、延寿、净化灵根、提升突破率。它连接"冒险 → 材料"和"修炼 / 突破 → 灵气"，是核心循环的关键一环。
炼丹完成时也可以获得灵气（成功获得较多，失败获得较少，整体低于修炼获得的灵气值）。

```
冒险 ──► 材料 ──► 炼丹 ──► 丹药 ──► 修炼 / 突破 / 延寿 / 净化灵根
```

---

## 2. 材料体系

### 2.1 设计目标

- **30+ 种材料**，每种带 1~2 个**词条**（品质 / 属性）。
- 材料按品阶分为 5 个等级：**凡品 → 中品 → 上品 → 极品 → 仙品**。
- 同一材料可在多个丹方中使用。

### 2.2 材料分类

| 大类 | 例子 | 主要用途 |
| --- | --- | --- |
| **草药** | 青灵草、九转还魂草、龙涎草 | 炼丹主料 |
| **矿石** | 玄铁矿、寒玉髓、朱砂 | 炼丹辅料 + 部分直接炼化 |
| **灵兽材料** | 妖丹、灵兽血、羽毛 | 炼丹辅料 + 特殊丹方 |
| **天材地宝** | 千年灵芝、九转还魂丹、扶桑叶 | 高阶丹方 |
| **五行精华** | 金精、水魂、火魄、木心、土魄 | 高阶丹方、净化灵根 |

### 2.3 词条系统

每个材料除了品阶外，还可能携带 1~2 个**词条**：

| 词条类型 | 例子 | 影响 |
| --- | --- | --- |
| **品质词条** | 纯净、杂质、陈年 | 炼丹成功率 ±10% |
| **属性词条** | 火属、水属 | 对应属性丹方成功率 +20% |
| **特殊词条** | 灵性、罕见 | 解锁特殊丹方 |

> 例：`青灵草（上品·纯净·木属）` 比 `青灵草（凡品·杂质）` 在木属性丹方中成功率显著更高。

### 2.4 材料的来源

| 来源 | 说明 |
| --- | --- |
| **冒险** | 主要来源，地图 + 难度决定材料品阶与词条 |
| **道友赠礼** | 部分道友会赠材料 |
| **奇遇事件** | 偶发获得珍稀材料 |
| **前世遗物** | 仅符合遗物规则的少量材料可保留（详见 [06-转生与多结局](./06-转生与多结局.md)） |

### 2.5 初始材料清单（MVP 范围，建议 30 种）

**草药类（10）**：
- 青灵草、九转还魂草、龙涎草、雪莲、朱果、紫金藤、灵芝、何首乌、桑寄生、七星海棠

**矿石类（8）**：
- 玄铁矿、寒玉髓、朱砂、辰砂、紫铜矿、磁石、灵玉、玄铁精

**灵兽材料（6）**：
- 妖丹（随机品阶）、灵兽血、羽毛、鳞片、骨、丹砂

**天材地宝（4）**：
- 千年灵芝、九转还魂丹草、扶桑叶、菩提子

**五行精华（5）**：
- 金精、水魂、火魄、木心、土魄

> 这只是 MVP 范围，后续扩展见 [09-分期路线图](./09-分期路线图.md)。

## 3. 丹方

### 3.1 丹方设计

- **当前 Demo MVP：9 种丹方**，每个大境界解锁 1 种，覆盖练气到渡劫。
- **完整 MVP 目标：20~30 种丹方**，在后续迭代中加入材料词条、探索发现与道友传授丹方。
- 每个丹方需要 **2~5 种材料** + 1~3 种特定材料组合。
- 丹方有**品阶**（凡 / 中 / 上 / 极），品阶决定产出丹药的品质上限。

### 3.2 MVP 境界解锁表

MVP 每提升一个大境界，炼丹页额外解锁一种丹方；已解锁的低阶丹方仍可继续炼制。丹方使用 MVP 的“灵草 / 灵矿”材料抽象，成功后获得对应丹药并可立即服用。

| 解锁境界 | 丹方 | 材料 | 服用效果 |
| --- | --- | --- | --- |
| 练气 | **培元丹** | 灵草 ×2 | 灵气 +50 |
| 筑基 | **凝元丹** | 灵草 ×3 + 灵矿 ×1 | 灵气 +180 |
| 金丹 | **金髓丹** | 灵草 ×4 + 灵矿 ×2 | 灵气 +600 |
| 元婴 | **婴华丹** | 灵草 ×5 + 灵矿 ×3 | 灵气 +1,800 |
| 化神 | **化神丹** | 灵草 ×6 + 灵矿 ×4 | 灵气 +5,000 |
| 炼虚 | **虚灵丹** | 灵草 ×7 + 灵矿 ×5 | 灵气 +20,000 |
| 合体 | **合道丹** | 灵草 ×8 + 灵矿 ×6 | 灵气 +100,000 |
| 大乘 | **大乘丹** | 灵草 ×9 + 灵矿 ×7 | 灵气 +500,000 |
| 渡劫 | **避劫丹** | 灵草 ×10 + 灵矿 ×8 | 灵气 +2,000,000 |

### 3.3 完整丹方示例

| 丹方 | 品阶 | 材料 | 产出 |
| --- | --- | --- | --- |
| **培元丹** | 凡 | 青灵草 ×2 + 水 ×1 | 凡品培元丹 ×1~2 |
| **聚气丹** | 中 | 青灵草 ×3 + 金精 ×1 | 中品聚气丹 ×1 |
| **回春丹** | 中 | 九转还魂草 ×2 + 灵芝 ×1 | 中品回春丹 ×1 |
| **延寿丹** | 上 | 灵芝 ×3 + 何首乌 ×2 + 木心 ×1 | 上品延寿丹 ×1 |
| **净灵丹** | 上 | 青灵草 ×5 + 五行精华 ×1 + 灵玉 ×1 | 上品净灵丹 ×1 |
| **筑基丹** | 上 | 九转还魂丹草 ×1 + 妖丹 ×1 + 火魄 ×1 | 上品筑基丹 ×1 |
| **破境丹** | 上 | 玄铁精 ×3 + 朱砂 ×2 + 龙涎草 ×1 | 上品破境丹 ×1 |
| **续命丹** | 极 | 千年灵芝 ×1 + 菩提子 ×1 + 木心 ×1 | 极品续命丹 ×1 |

### 3.4 丹方的获取

| 方式 | 说明 |
| --- | --- |
| **默认解锁** | 角色创建时解锁培元丹 |
| **境界解锁** | 每提升一个大境界解锁 1 种当前 Demo 丹方 |
| **冒险发现** | 冒险中随机发现新丹方（残页 / 老修口授） |
| **道友传授** | 高好感度道友传授 |
| **转生继承** | 部分丹方可被继承 |

### 3.5 炼丹成功率

```
炼丹成功率 = clamp(难度基础成功率 × 材料品阶倍率 × 材料词条倍率 + 境界加成 + 道友协助加成, 5%, 95%)
```

| 因素 | 基础值 |
| --- | --- |
| **难度基础成功率** | 轻 / 中 / 重 / 超 = 80% / 70% / 60% / 50% |
| **材料品阶匹配** | 80% ~ 120% |
| **材料词条** | × 1 ~ × 1.2 |
| **境界加成** | 当前境界层数 × 1 个百分点 |
| **道友协助** | + 5 ~ 15 个百分点 |

> 例：练气 5 层，中难度、无道友、材料品阶匹配且词条倍率 ×1.2：70% × 100% × 1.2 + 5% = 89%。

### 3.6 炼丹失败

- 失败后材料**部分损毁**（随机 30% ~ 80% 损失），不会全部损失。
- 失败不会在行为成本之外额外扣寿元，也不会造成角色伤害（炼丹失败 ≠ 走火入魔）。
- 连续失败会触发"丹师心得"叙事事件。

## 4. 丹药种类

### 4.1 丹药大分类

| 类别 | 例子 | 主要作用 |
| --- | --- | --- |
| **修炼类** | 培元丹、聚气丹 | 直接增加灵气 |
| **延寿类** | 延寿丹、续命丹 | 提升寿元上限 |
| **破境类** | 筑基丹、破境丹 | 提升突破成功率 |
| **净化类** | 净灵丹 | 提升灵根资质 |
| **疗伤类** | 回春丹、九转金丹 | 解除重伤、起死回生 |
| **特殊类** | 化形丹、避劫丹 | 后期 / 剧情向 |

### 4.2 后续丹药规划

| 丹药 | 品阶 | 效果 |
| --- | --- | --- |
| **培元丹** | 凡 | 灵气 +50 |
| **回元丹** | 凡 | 灵气 +30，寿元 -0.1 年 |
| **聚气丹** | 中 | 灵气 +200 |
| **回春丹** | 中 | 解除"轻伤"状态 |
| **筑基丹** | 上 | 练气大圆满时突破 +20% |
| **延寿丹** | 上 | 寿元上限 +10 年 |
| **净灵丹** | 上 | 灵根资质 +1（边际递减） |
| **破境丹** | 上 | 突破成功率 +15% |
| **化瘀丹** | 上 | 解除"重伤"状态 |
| **凝魂丹** | 上 | 突破失败时减少跌落层数 |
| **续命丹** | 极 | 寿元上限 +50 年 |
| **九转金丹** | 极 | 寿元 +30 年，解除重伤，悟性 +1 |

> 本表为 1.x / 2.x 的扩展规划；当前可炼制与可服用的丹药以 §3.2 的九种境界解锁丹方为准。

### 4.3 MVP 服用规则

- 当前可炼制的 **培元丹** 可由玩家在炼丹页主动服用，每颗消耗 1 枚丹药并获得灵气 `+50`。
- 服用后立即进行层数判定；若达到大圆满，修炼页显示“尝试突破”入口。
- 培元丹不是破境丹，不会在突破时自动消耗或增加突破成功率。
- 服药结果写入修炼历程，不额外弹出确认窗口。

## 5. 炼丹交互流程
炼丹过程不需要用户手动操作，用户只需要选择“炼丹“行为时，可选炼丹难度/丹方，若用户未手动选择则丹方/难度，则推进寿元进度条时直接随机选择材料充足的丹方/难度进行炼丹。

```
[选择丹方]  ──►  [选择炼丹难度]  ──►  [提交]
                                     │
                                     ▼
                                 [进度条几秒]  ──►  [结算]
                                                      │
                                                      ▼
                                                 成功：[获得丹药] + 文字描述
                                                 失败：[损失材料] + 文字描述
```

### 5.1 炼丹的难度分层

| 难度 | 寿元消耗 | 产出数量 | 成功率 |
| --- | --- | --- | --- |
| 轻 | 1 月 | 1 | 80% |
| 中 | 1 季 | 1~2 | 70% |
| 重 | 1 年 | 2~3 | 60% |
| 超 | 5 年 | 3~5 | 50% |

> 与修炼、冒险一致：难度越高，单次收益越大，寿元压力越大。

### 5.2 取消规则

与修炼、冒险一致：取消退还部分寿元（详见 [01-核心循环 §3.2](./01-核心循环.md)）。

### 5.3 炼丹奇遇

- 每次炼丹结算有 **8%** 概率触发奇遇，与修炼、游历共用 20 条剧情事件库。
- 抽取时排除最近 3 次已结算的奇遇，避免短时间重复看到同一剧情。
- 奇遇抉择结束后，恢复炼丹自动计划；结果写入修炼历程。

## 7. 炼丹的叙事与文案

炼丹不仅是数值行为，也是叙事点：

- **炼丹成功**：出现祥瑞、香满十里的文字描述。
- **炼丹失败**：出现焦糊、炸炉等文字描述，损失材料。
- **炼丹顿悟**：极低概率（1%）炼丹中触发"丹道顿悟"，额外增加灵气获得值。

---

## 8. 后续扩展（1.x / 2.x）

- **丹药品阶扩展**：增加仙品、神品。
- **丹方变异**：同一丹方根据材料词条产出不同变种（如"九转金丹"可变异为"九转还魂金丹"）。
- **炼丹流派**：玩家可选择专精一种属性（专精加成）。
- **炼丹炉系统**：不同炉子影响炼丹品质。
