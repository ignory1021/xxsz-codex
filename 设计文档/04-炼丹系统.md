# 04 · 炼丹系统

炼丹是本版本的主要成长方式。详细经济循环见 [10-炼丹主线与经济](./10-炼丹主线与经济.md)。

---

## 1. 定位

```
探索 → 材料 → 炼丹 → 丹道经验 + 丹药 → 境界 / 出售 / 装备与补给
```

- **丹道经验**：成功炼丹的主要产出，用于境界层级与突破进度。
- **丹药**：可自行服用以获得功能效果，也可在集市出售为灵石。
- **灵石**：支付路费、炉费、装备与恢复品，迫使玩家在自用与出售之间取舍。

## 2. 炼丹流程

```
[选择丹方] → [检查材料、精力、炉费与寿元] → [炼制结算] → [记录经验、丹药与年龄]
```

- 玩家每次选择丹方后只炼制一次，不自动续行。
- 成功：获得丹道经验与成丹，写入修行历程。
- 失败：损失部分材料与已付炉费，不获得成丹；失败结果以文字描述记录。
- 材料、精力或灵石不足时，无法开始炼制并显示原因；不会自动出售丹药或购买恢复品。
- 基础丹药炼制消耗 **10 天**，高阶丹药炼制消耗 **30 天**；中间丹药的行动天数在数值表中补齐。

## 3. 丹方与境界

- 境界提升会解锁更高阶丹方、集市装备品级和探索地图。
- 高阶丹方使用更稀缺的材料、支付更高炉费，提供更多丹道经验和更高出售价值。
- 丹药效果覆盖：恢复、战斗辅助、灵根调整、延寿、突破辅助等；每个效果必须在丹方信息中公开说明。

## 4. 经济关系

- 低阶丹药保证基础资金循环，避免玩家因一次失败而无法继续探索。
- 中高阶丹药提供更高利润，但需要从危险地图取得材料，并承担更高失败成本。
- 炉费是每次炼丹的直接消耗；装备、恢复品与路费构成持续消费，不让灵石只增不减。

## 5. 本轮 MVP 边界

- 实现材料、丹道经验、丹药、出售、炉费、精力与寿元天数消耗，以及单次炼丹。
- 丹炉本体默认可用且没有耐久，不做炉阶、耐久、修复或更换。
- 后续加入丹炉升级、折损与修复，作为中后期灵石消耗与炼丹成功率调节手段。
