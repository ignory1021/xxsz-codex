## 2. 五行灵根与派生属性（提案）

### 2.1 根值生成

- 每项根值范围为 **1 ~ 10**，总和固定为 **25**。
- 新角色先为五项灵根各分配 1 点，再随机分配 20 点；单项达到 10 后不再继续分配。
- 根值 5 是中性基准。总和固定让角色形成路线差异，而不会出现全属性都极高的开局。
- 净灵丹每次使指定根值 +1，最高 10；只对当前一世生效，不消耗寿元。

### 2.2 层级放大系数

设当前大境界序号为 `R`（练气 = 1，渡劫 = 9），当前层级为 `L`（1 ~ 10）：

```
灵根发挥系数 S = 1 + 0.08 × (R - 1) + 0.02 × (L - 1)
```

`S` 从练气一层的 `1.00` 增长到渡劫十层的 `1.82`。这使后期灵根差异更明显，但不会替代装备、经济与行动选择。

### 2.3 公式

| 灵根 | 公式 | 说明 |
| --- | --- | --- |
| 火 | 成丹率 = `clamp(基础成丹率 + (火 - 5) × 1.5% × S, 5%, 95%)` | 火根高时提高成功率 |
| 火 | 丹道经验 = `round(基础经验 × (1 + (火 - 5) × 3.5% × S))` | 只在成功炼丹后生效 |
| 金 | 攻击 = `round((境界基础攻击 + 装备攻击) × (1 + (金 - 5) × 3.5% × S))` | 用于文字战斗 |
| 土 | 防御 = `round((境界基础防御 + 装备防御) × (1 + (土 - 5) × 3.5% × S))` | 用于文字战斗 |
| 水 | 生命上限 = `round((境界基础生命 + 装备生命) × (1 + (水 - 5) × 5% × S))` | 当前生命不超过上限 |
| 木 | 额外材料概率修正 = `clamp((木 - 5) × 4% × S, -18%, 24%)` | 加到地图 30% 的额外材料掉落概率 |
| 木 | 材料数量概率修正 = `clamp((木 - 5) × 3% × S, -14%, 18%)` | 加到材料 10% 的额外 +1 掉落概率 |

`clamp` 表示将结果限制在给定区间内。木灵根不会减少地图的保底材料，只影响额外掉落与额外数量。

## 4. 文字战斗（提案）

### 4.1 结算公式

遭遇妖物时，玩家选择“迎战”或“退避”。不做回合制展示，但系统按以下公开规则一次结算：

```
玩家单次伤害 = max(1, 玩家攻击 - 妖物防御 × 0.4)
妖物单次伤害 = max(1, 妖物攻击 - 玩家防御 × 0.4)
击败所需轮数 = ceil(妖物生命 / 玩家单次伤害)
预计承伤 = 击败所需轮数 × 妖物单次伤害
```

- 当前生命大于预计承伤：迎战胜利，扣除预计承伤，获得基础收益与额外战利品。
- 当前生命不大于预计承伤：迎战失败，生命降至 1，保留基础材料，失去本次额外战利品，并有 30% 概率获得“轻伤”。
- 轻伤期间探索体力消耗 +5、炼丹精力消耗 +5；调息一次或服用回春类丹药后解除。
- 退避不扣生命，保留基础材料，但不获得额外战利品。
- 生命归零不导致角色死亡；当世死亡只由寿元耗尽触发。

#### 5.2.1 使用与效果规则

- 每次成功炼丹获得 1 颗对应丹药。表中成丹率为灵根、同行等加成计算前的基础值；丹道经验仅在成功时获得。
- 恢复、灵根调整、延寿、好感与破境丹即时生效且不推进寿元；攻防与采集辅助丹必须在行动前服用。
- 同类临时效果不叠加，重复服用仅刷新持续行动次数；攻、防与采集属于不同效果类别，可以同时生效。临时效果在转世时清除。
- 破境丹只能在对应突破的确认面板中使用，并作为该次突破的必需消耗；成功率加成随本次判定结算，不能预先服用或保留到下一次。渡劫飞升时须在同一次确认中消耗归一丹与登仙丹，两者加成相加。
- 延元丹每世最多服用 3 颗；净灵丹每一项灵根最高只能调整至 10；养魂丹和合道丹的目标好感度均不超过 100。好感丹药只能对已结识且未绝交的道友使用。
- 回春散、化瘀丹与补天丹均属于回春类丹药，可用于玩家自用或道友重伤抢救。抢救需消耗 1 颗，成功率 80%；成功解除重伤并使目标完全恢复，失败时丹药照常消耗、目标保持重伤。
- 表内“售出价”为集市固定回收价。集市不出售表内丹药，因此不存在买入转售；出售和服用均需要玩家主动确认。

## 6. 层级、突破与渡劫（提案）

### 6.1 层级经验插值

现有经验表只给出首层、末层与大圆满节点。中间层统一使用线性插值：

```
第 L 层升至第 L+1 层所需经验
= round(首层经验 + (末层经验 - 首层经验) × (L - 1) / 8)
```

其中 `L` 为 1 ~ 9；10 层升大圆满使用原表的“大圆满”数值。丹道经验在当前境界内累计，突破成功后清零并进入下一境界一层。

### 6.2 突破前置

| 突破 | 必须丹药 | 额外材料 | 基础成功率 |
| --- | --- | --- | ---: |
| 练气 → 筑基 | 筑基丹 | 碎灵砂 ×1 | 90% |
| 筑基 → 金丹 | 结丹丹 | 百年藤芯 ×1 | 75% |
| 金丹 → 元婴 | 凝婴丹 | 金髓矿 ×1 | 60% |
| 元婴 → 化神 | 化神丹 | 月华草 ×1 | 45% |
| 化神 → 炼虚 | 炼虚丹 | 地心髓 ×1 | 30% |
| 炼虚 → 合体 | 合体丹 | 星砂 ×1 | 20% |
| 合体 → 大乘 | 大乘丹 | 天罡晶 ×1 | 15% |
| 大乘 → 渡劫 | 渡厄丹 | 太初石 ×1 | 10% |
| 渡劫 → 飞升 | 归一丹 + 登仙丹 | 混沌莲子 ×1、仙髓 ×1 | 5% |

突破不推进寿元。表中的破境丹为对应突破的必需消耗，且只在该次突破中提供成功率加成；悟性与悟道点不进入 MVP，不参与生成、存档或突破。

### 6.3 渡劫失败

- “继续修炼”：回到渡劫大圆满，保留当前寿元与物品，可再次准备渡劫。
- “散功”：当前年龄增加至寿元上限，转生。
- “兵解”：立即结束当世，转生。

## 7. 道友同行（提案）

### 7.1 资格与时间

- 好感度达到 50（知交）后可设为同行；一次最多 1 名。
- 同行道友参与探索、炼丹与调息时，与玩家同步推进本次随机天数；不同行道友不自动老去或行动。
- 同行使新道友相逢概率乘以 `0.4`。探索基础相逢率因此从 10% 降为 4%。

### 7.2 每次同行行动的效果

| 行动 | 同行效果 |
| --- | --- |
| 探索 | 额外进行一次“协作采集”判定，40% 概率获得 1 份当前地图基础材料；文字战斗中玩家攻击、防御各 +8% |
| 炼丹 | 成丹率 +5 个百分点，成功后的丹道经验 +10% |
| 调息 | 额外回复生命上限的 10% |

同行加成与灵根、装备、丹药正常叠加；成丹率最终仍限制在 5% ~ 95%。

### 7.3 好感度波动

每次同行行动结算后进行一次关系判定：

| 结果 | 概率 | 好感变化 |
| --- | ---: | --- |
| 默契同行 | 50% | +1 ~ +3 |
| 平常相伴 | 35% | 0 |
| 意见相左 | 15% | -1 ~ -3 |

额外规则：同行迎战失败时额外 -3 ~ -6；炼丹失败时额外 -1 ~ -2。变化写入修行历程，但事前不展示结果。

### 7.4 道友重伤与死亡

- 同行迎战失败后，有 15% 概率使道友重伤。
- 重伤道友再次在同行迎战失败后触发重伤判定时，改为死亡。
- 抢救消耗 1 颗回春类丹药（回春散、化瘀丹或补天丹）；成功率 80%，成功后解除重伤并增加 20 好感度，失败则丹药照常消耗且保持重伤。
- 道友死亡保留叙事、纪念和转世重逢规则；不同行道友不发生随机死亡事件。
