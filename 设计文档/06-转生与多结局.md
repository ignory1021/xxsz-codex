# 06 · 转生与多结局

本文档定义转生机制、飞升路线、多结局与世系记录档。

---

## 1. 设计的核心意图

- **转生** = 常规循环 + 因缘延续，鼓励玩家**多世游玩**。
- **开新游戏** = 重置全部，**不继承**任何前世。
- **飞升** = 当前世的真结局，是单世长期目标。
- **世系记录档** = 玩家回顾多世游玩历史的载体。

---

## 2. 转生

### 2.1 触发条件

寿元耗尽（当前寿元 ≥ 上限）= 死亡 = 自动弹出转生选项。

### 2.2 转生交互

```
[寿元耗尽]  ──►  [死亡叙事文案]  ──►  [转生确认弹窗]
                                          │
                            ┌─────────────┴─────────────┐
                            ▼                           ▼
                       [转生]                     [开新游戏]
                            │                           │
                            ▼                           ▼
                   重置个人资质 + 延续部分因缘   全部重置
                   记录档追加一世              记录档清空
```

### 2.3 转生时继承的内容

| 项 | 是否继承 | 备注 |
| --- | --- | --- |
| **五行灵根分布** | ❌ | 每一世独立随机生成，不继承上一世根值 |
| **灵根调整效果** | ❌ | 当前一世的丹药或事件调整全部清零 |
| **已解锁丹方** | ❌ | 全部重置，重新取得或解锁 |
| **已解锁地图** | ❌ | 全部重置，随新一世境界重新开放 |
| **部分道友** | ⚠️ 部分 | 见 §3 |
| **材料 / 丹药** | ❌ | 全部重置 |
| **灵石 / 装备 / 补给** | ❌ | 全部重置 |
| **境界 / 丹道经验** | ❌ | 重置回练气 1 层 |
| **当前寿元** | ❌ | 重置为 0 |
| **寿元上限** | ❌ | 回到练气 50 年 |

### 2.4 转生时的个人重置

- 新角色的五行灵根分布、境界与寿元均重新生成或重置；不参考上一世的灵根状态。
- 丹道经验、丹方、材料、丹药、灵石、装备、体力、精力与所有消耗品全部清零。
- 前世角色数值只写入世系记录档，不为新角色提供隐藏加成。
- 多世持续内容仅保留世系记录与可触发的道友转世重逢。

---

## 3. 转生时的道友继承

### 3.1 保留规则

道友在以下条件下可被转生继承：

| 条件 | 保留概率 |
| --- | --- |
| 好感度 ≥ 70（莫逆） | 100% 保留 |
| 好感度 50 ~ 69（知交） | 50% 保留 |
| 好感度 30 ~ 49（点头之交） | 20% 保留 |
| 好感度 < 30 | 0% |
| 道友已死亡 | 按死亡前好感度计算 |
| 道友已绝交 | 0% |

### 3.2 保留后的变化

- 道友以**转世后的新身份**出现，姓名、年龄、灵根、性格重新生成，但保留关联前世的魂识 ID。
- 好感度重置为 **继承值的 50%**（如上世 80 → 新一世 40）。
- 境界不保留；重逢时按玩家当前境界生成，与普通新识道友规则一致。
- 与道友的"特殊事件 / 记忆"会被保留为"前世因果"叙事碎片。

### 3.3 设计意图

- 让玩家感觉"前世的情谊今世再续"。
- 不会让道友过于强大（新一世重置境界，并折半好感度）。
- 高好感度道友值得长期培养。

## 4. 飞升

### 4.1 触发条件

- 处于**渡劫大圆满**。
- 寿元未耗尽。
- 背包中持有归一丹、登仙丹、混沌莲子 ×1 与仙髓 ×1。

MVP 不设置额外的识友、奇遇或隐藏剧情门槛；两枚丹药与两种材料是唯一前置，避免剧情内容未补齐时阻断飞升。

### 4.2 渡劫

渡劫是**特殊形式的"突破"**，有独立的叙事和数值：

| 项 | 数值 |
| --- | --- |
| 基础成功率 | 5% |
| 寿元消耗 | 0 天 |
| 失败后果 | 见 §4.4 |

### 4.3 渡劫成功 = 飞升

- 进入"飞升"境界 = 游戏结束。
- 弹出大幅飞升叙事文案 + 结局画面。
- 玩家**必须选择**：
  - **开启新一世**（重置个人资质 + 延续部分道友因缘，记录档追加）。
  - **开新游戏**（全部重置）。

### 4.4 渡劫失败

- 不再"跌落层数"（渡劫已是最高）。
- 选项：
  - **继续修炼**：返回渡劫十层，重新满足大圆满条件后可再次渡劫。
  - **散功**：立即结束当世并转生；不保留当前境界、寿元、资产或物品。
  - **兵解**：立即结束当世并转生；不保留当前境界、寿元、资产或物品。

散功与兵解都记录为当世结局，区别只体现在叙事文案；转生继承范围仍严格遵循 §2.3。

> 飞升的设计意图：让单世结束有正向反馈（多结局），并丰富世系与因缘叙事；开启新一世后不继承任何数值、资产、装备、材料、丹药或功法加成。

## 5. 多结局

### 5.1 MVP 结局列表

| 结局 | 触发条件 | 描述 |
| --- | --- | --- |
| **完美飞升** | 渡劫成功，且当世没有已死亡道友、没有主动绝交记录 | "破界飞升，踏入仙界" |
| **残缺飞升** | 渡劫成功，且不满足完美飞升条件 | "飞升路上心魔未净，踏入仙界但根基有瑕" |
| **散人** | 大乘一层及以上，在角色卡主动选择“散功归隐”并二次确认 | "放弃长生，归隐山林" |
| **兵解** | 渡劫失败选择兵解 | "舍去此身，因缘重入轮回" |
| **凡人** | 寿元耗尽且境界低于筑基 | "凡人寿尽，未能踏入仙途" |
| **修士** | 寿元耗尽且境界筑基~金丹 | "修士之路未尽，转世重来" |
| **真人** | 寿元耗尽且境界元婴~化神 | "真人转世，重修正道" |
| **仙苗** | 寿元耗尽且境界炼虚及以上 | "前世已近仙道，因缘留痕，转世重修" |

### 5.2 结局的记录

每次结局都记录到世系记录档，玩家可在记录档查看每一世的：

- 主角姓名 / 性别 / 性格 / 灵根
- 起始与结束时间
- 最高境界
- 总寿命
- 识友数 / 死亡友人数
- 炼丹数 / 突破次数
- 最终结局类型

### 5.3 结局的解锁与展示

- 每个结局第一次达成时弹"结局解锁"提示。
- 记录档可永久查看所有解锁的结局。

## 6. 世系记录档

### 6.1 结构

```
[第一世]
  - 主角信息
  - 起始 / 结束时间
  - 最高境界：练气大圆满
  - 总寿命：30 年
  - 结局：凡人
  - 重大事件：xxx

[第二世]
  ...

[第三世]
  ...
```

### 6.2 记录档的访问

- 主菜单 → "世系" 入口。
- 玩家可以在世系中**点击某一世**查看完整事件流水。

### 6.3 记录档与"开新游戏"

| 玩家操作 | 记录档是否保留 |
| --- | --- |
| 寿元耗尽 → 转生 | ✅ 追加一世 |
| 飞升 → 选择"开启新一世" | ✅ 追加一世 |
| 飞升 → 选择"开新游戏" | ❌ 全部清空 |
| 主菜单 → "开新游戏" | ❌ 全部清空 |
| 清浏览器缓存 / 卸载 | ❌ 全部丢失（MVP 无云存档） |

> 主菜单的"开新游戏"会**二次确认**，避免误操作。

## 8. 后续扩展（1.x / 2.x）

- **真结局 / 隐藏结局**：基于世系累计触发的特殊结局。
- **跨世 NPC**：某些高阶 NPC 在多世中扮演关键角色。
- **前世记忆**：未来可扩展为基于因缘与世系记录触发的叙事碎片，不提供隐藏数值加成。
- **大轮回**：完成 N 世后开启新的"纪元"，解锁更高境界。
