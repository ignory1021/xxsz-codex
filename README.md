## 项目简介

参考《某某宗女修修炼手札》《药王谷女修修炼手札》的核心循环，朝"挂机可中断、可暂停、可异步推进"的方向收敛。

- **形态**：模块化文字放置 / 挂机游戏
- **平台**：手机网页（响应式）→ 安卓 APK（后期）
- **风格**：古风水墨 + 典雅文言
- **节奏**：短反馈、快节奏，1~5 分钟即可推进
